### 1．【経済】4～6月GDP、年率1.4％へ上方修正　でも個人消費は横ばい

**何が起きたか**

内閣府が8日発表した2026年4～6月期GDPの2次速報で、物価変動を除く実質成長率は前期比0.4％、年率換算1.4％となった。1次速報の年率1.1％から上方修正された。設備投資は前期比マイナス0.9％と、速報のマイナス1.2％から下げ幅が縮小。一方、GDPの半分以上を占める個人消費は横ばいだった。

**賛**

中東情勢や物価高という逆風がある中でも、景気全体がマイナスへ落ちなかったのは悪くない。設備投資の弱さも速報時より少しマシになり、日銀が「景気が崩れて利上げどころではない」と言う状況からは遠ざかった。

**ただぁ！**

GDPは上方修正されたのに、家計の主役である個人消費は横ばい。マクロ経済は「1.4％成長です」と胸を張っている横で、財布は椅子に座ったままである。

**結論**

景気後退ではない。でも「景気いいね」と言うには、まだ家計側の返事が薄い。数字の上方修正より、消費が次の四半期でちゃんと立ち上がるかが本番だ。

### 2．【経済】円、一時1ドル152円台　昨日は「介入の請求書」、今日は市場だけで円高が進む

**今回の差分**

7日は過去最大規模の円買い介入が外貨準備の減少として表れた話を扱った。8日は新たな介入ではなく、日銀の利上げ観測や円キャリー取引の巻き戻しを背景に、円相場そのものが一時152円88～89銭まで上昇した。

**何が起きたか**

8日の東京外国為替市場で円は一時1ドル＝152円88～89銭と、2月以来およそ7カ月ぶりの円高水準を付けた。先週初めの160円前後からは約4％上昇。市場では9月17～18日の日銀会合で0.25％の追加利上げを予想する動きが強まった。ただ午後には原油高や米長期金利上昇を受け、17時時点では154円前後まで戻している。

**賛**

昨日のように外貨準備を何兆円も使わず、市場の金融政策見通しだけで円高が進むなら、その方が持続可能ではある。介入より「金利差が縮まりそう」という理由で買われる方が、通貨としては自然だ。

**ただぁ！**

午前に152円台まで行って、夕方には154円台。円高ニュースを昼休みに読んだ人と、退勤時に見た人で感想がもう違う。

**為替、速報の賞味期限が弁当より短い。**

**結論**

152円台は節目だが、定着したわけではない。9月の日銀会合までは「円高になった」より「円高方向へ振れやすくなった」と見る方が安全だ。

### 3．【暮らし・消費】ステーキ632人前で牛の個体識別番号を表示せず　農水省がレスト関ヶ原へ勧告

**何が起きたか**

農林水産省は8日、岐阜県関ケ原町の「レスト関ヶ原」に対し、牛トレーサビリティ法に基づく勧告を行った。運営する「鉄板ダイニング天満」で、フィレステーキ鉄板焼など3品に使った牛肉の一部について個体識別番号を表示せず、少なくとも2025年8月～2026年4月に57.2kg、632人前を提供していた。農水省は表示の是正、原因分析、再発防止などを求めている。

**賛**

牛の個体識別番号は、問題が起きた際に生産・流通履歴を追えるようにするための制度だ。普段は客が番号を毎回検索しなくても、「必要になった時に辿れる」状態を維持すること自体に意味がある。

**ただぁ！**

店名は関ヶ原なのに、牛の履歴だけ行方不明になっていた。

歴史の天下分け目は400年前でいい。ステーキの出どころまで霧の中にする必要はない。

**結論**

今回確認されたのは表示義務違反で、牛肉そのものの安全性問題が発表されたわけではない。だからこそ、余計に「番号くらいちゃんと出そう」で終わる話でもある。

主な参照元：[農林水産省](https://www.maff.go.jp/j/press/syouan/kansa/260908.html)、[東海農政局](https://www.maff.go.jp/tokai/press/hyoji/260908.html)

### 4．【科学】高温超伝導体に「もう一つの周期」　東北大など、ペア密度波の手掛かりを観測

**何が起きたか**

東北大学などの研究チームは8日、La系銅酸化物の高温超伝導体で、主要な電荷密度波（CDW）の2倍の周期を持つ弱い「サブハーモニック応答」を共鳴軟X線散乱で観測したと発表した。この応答は、電子対の密度が空間的に波打つ「ペア密度波（PDW）」の相関と整合するという。論文はPhysical Review Bに掲載された。

**賛**

高温超伝導は、発見から何十年たっても「なぜそうなるのか」が完全には片付いていない。見えにくかった電子秩序を別の周期として拾えたことで、PDWを実験的に探る新しい指標になる可能性がある。

**ただぁ！**

「超伝導の謎を解明」と書きたくなる見た目だが、今回はPDWそのものを最終確定したわけではなく、**PDWと整合する応答を見つけた**段階。

量子物理、見出しを一段盛るだけでノーベル賞まで瞬間移動しがち。

**結論**

派手な製品化ニュースではない。でも基礎研究では、こういう「今まで見えなかった痕跡」が後から効く。超伝導の説明書に、また一行増えた。

主な参照元：[東北大学](https://www.tohoku.ac.jp/japanese/2026/09/press20260908-01-subharmonic.html)、[東北大学金属材料研究所](https://www.imr.tohoku.ac.jp/en/news/results/detail---id-1921.html)

**賛**

10月に打者として出られなくなるくらいなら、9月の数登板を捨てる方が合理的だ。二刀流のロマンより、ポストシーズンで確実に使える戦力を残す方がチームには大事になる。

二刀流の選手が「今年は打者に専念」と言うと、一瞬弱体化したように聞こえる。

**結論**

今季の投手・大谷はほぼ店じまい。でも打者・大谷まで休業する必要はない。今は二刀流を守るために、一刀流へ戻す時期だ。

### 10．【科学・医療】Novartisの筋強直性ジストロフィー薬、第3相で主要評価項目未達　株価10％安

**何が起きたか**

Novartisは8日、筋強直性ジストロフィー1型（DM1）向けの開発薬del-desiranについて、約150人を対象とした第3相HARBOR試験で主要評価項目を達成できなかったと発表した。手の筋強直を測るvideo hand opening timeで、プラセボに対する統計的に有意な改善を示せなかった。二次・探索的評価項目では臨床活性を示す兆候があり、同社は全データを解析して今後の開発方針を判断する。Reutersによると株価は一時約10％下落した。

**賛**

第3相で期待通りにならなくても、二次評価や安全性を含むデータは次の研究に残る。特にDM1には承認済み治療がないため、失敗を隠さず結果を出して次の開発判断へ進むこと自体が重要だ。

Novartisは今週、別の心血管薬pelacarsenでも主要試験が未達だった。大型買収で増やした「将来の柱」が、同じ週に二本続けて検査入院しているような格好だ。

ただし、患者にとっては株価より「効く治療がまだない」ことの方が圧倒的に重い。

**結論**

新薬開発は、期待額を積めば成功率まで上がる商売ではない。今回は企業価値の話より、DM1で次の有効な候補をどう残すかが本題だ。
