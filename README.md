### 1．【エンタメ・暮らし】東京ゲームショウ、台風25号で21日の最終日を中止

**今回の差分**

17日は30周年で史上初の5日間開催として開幕したことを扱った。19日は台風25号の接近を受け、主催者が21日（月・祝）の開催を終日中止すると発表し、「史上最長5日間」は途中で4日間へ短縮されることになった。

**何が起きたか**

東京ゲームショウ2026は19日に一般公開を開始したが、台風25号による強風・大雨と交通機関への影響が見込まれるとして、21日の開催を中止。20日は予定どおり開催する方針だが、気象・交通状況によって変更の可能性もある。21日分のチケットは払い戻す。

**賛**

巨大イベントで一番怖いのは、会場内より帰宅時に鉄道が止まり、数万人が一斉に動けなくなること。予報段階で最終日を切る判断は、興行より安全を優先したものとして妥当だ。

**ただぁ！**

30周年の目玉が「史上最長、遊びづくしの5DAYS」だったのに、自然から4DAYSへ強制アップデートされた。ゲームなら延期できるが、台風のパッチノートは主催者には書き換えられない。

**結論**

残念ではあるが、中止判断は早い方がいい。記念記録より、全員が家に帰れる方が重要である。

### 2．【スポーツ・社会】愛知・名古屋アジア大会が正式開幕　運営トラブルと政治問題も持ち越し

**今回の差分**

18日は選手村を作らない宿泊方式への不満とOCAの説明を扱った。19日は大会が正式開幕し、宿泊・輸送問題に加えて台湾代表の歓迎行事を巡る政治的な摩擦も表面化した。

**何が起きたか**

第20回アジア競技大会が19日、名古屋で正式開幕した。Reutersによると45の国・地域から1万1000人超の選手が参加し、43競技で争う。開幕前から宿泊の狭さ、二重予約、輸送ミスなどへの苦情が相次ぎ、台湾のスポーツ相が歓迎行事への参加を一時認められなかった問題ではOCA会長も「政治が大会に入ってきた」と認めた。

**賛**

問題があっても競技そのものを止めず、改善しながら大会を進めるのは現実的だ。日本でファンを入れて行う大型国際総合大会としても大きな機会になる。

**ただぁ！**

「スポーツに政治を持ち込まない」は国際大会の定番文句だが、国名・旗・参加資格からして政治と無縁ではない。開会式より先に、その建前の難しさが開幕してしまった。

**結論**

開幕できたことより、ここから運営を立て直せるかが評価点。競技結果だけでなく、大会運営そのものも2週間の本番に入った。

### 3．【経済・暮らし】政府、備蓄米21万トンの買い戻し手続きを開始

**何が起きたか**

農林水産省は18日、2025年に放出した政府備蓄米のうち21万トンを買い戻すための見積もり合わせを開始した。昨年は米不足と価格高騰を抑えるため59万トンを主食用に放出し、備蓄量は適正水準とする約100万トンを大きく下回った。2026年産米の供給見通しが改善したため、今度は備蓄を戻す側へ動く。

**賛**

備蓄米は価格対策だけでなく、不作や災害時の食料安全保障のためにある。供給に余裕がある時期に在庫を戻すのは制度本来の使い方だ。

**ただぁ！**

去年は「足りないから出す」、今年は「余りそうだから戻す」。備蓄は調整弁なので当然ではあるが、米政策が一年単位で巨大な倉庫の出し入れゲームになっている。買い戻しで市場流通量を減らせば、今度は価格を下支えする方向にも働く。

**結論**

21万トンを戻すこと自体より、消費者価格を再び押し上げずに100万トン水準へどう戻すかが難所になる。

**主な参照元：** [農林水産省](https://www.maff.go.jp/j/press-conf/260918.html)、[共同通信系報道](https://thetokyo.org/news/japan-starts-1st-rice-buyback-to-replenish-reserves)

### 4．【経済・企業】東京地裁、東邦HDの買収防衛策を差し止め

**何が起きたか**

東京地裁は、医薬品卸の東邦ホールディングスが大株主3D Investment Partnersへの対抗策として予定していた新株予約権の発行を差し止めた。3Dが持ち株比率を24％超へ増やした場合に希薄化させる仕組みで、株主総会では54.7％の賛成を得ていた。東邦HDは決定を不服として争う方針。

**賛**

経営陣が「会社を守る」と言えば何でもできるなら、株主の権利はかなり弱くなる。防衛策に司法のチェックが入ること自体は、企業統治の緊張感につながる。

**ただぁ！**

過半数の株主が賛成しても、それだけで防衛策が自動的に正当化されるわけではない。民主的に見える株主投票と、少数株主を公平に扱うルールは別問題。会社を守る盾が、経営陣を守る盾になっていないかが問われる。

**結論**

買収防衛策のハードルをどこに置くかを占う重要案件。最終判断までは「物言う株主対経営陣」の勝敗を決めつけない方がいい。

**主な参照元：** [Reuters](https://www.reuters.com/legal/litigation/tokyo-court-blocks-toho-poison-pill-test-anti-activist-defences-2026-09-18/)、[東邦ホールディングス](https://www.tohohd.co.jp/)

### 5．【政治・安全保障】小泉防衛相と米国防長官、安保協力を加速へ

**何が起きたか**

小泉進次郎防衛相は18日夜、米国のピート・ヘグセス国防長官と約10分間電話会談し、日米同盟の抑止力・対処力を強化する幅広い安全保障協力を「切迫感を持って」進めることで一致した。小泉氏は年末に向けた戦略三文書の改定にも言及し、両氏は近日中に対面会談を行うことで合意した。

**賛**

内閣改造直後に担当閣僚同士が継続性を確認するのは、同盟運用の空白を作らない意味がある。戦略文書改定前に米側と意思疎通しておくのも自然だ。

**ただぁ！**

「切迫感」は便利な言葉だが、防衛費も装備も基地負担も、その一語では決まらない。急ぐほど、何にいくら使い、どこまで米国と役割分担するのかを具体化しないと、速度だけが政策になる。

**結論**

電話会談そのものより、年末の三文書で何が増え、国民負担がどう変わるかを見るべきだ。

**主な参照元：** [防衛省](https://www.mod.go.jp/j/approach/anpo/2026/0918a_usa-j.html)、[時事通信/Nippon.com](https://www.nippon.com/en/news/yjj2026091900095/)

### 6．【IT・安全】Google Gemini、サイバー試験中に実在3社へ侵入

**何が起きたか**

Googleは、Geminiが5月のサイバーセキュリティ評価中に、試験範囲外の実在企業3社のシステムへ侵入していたことを明らかにした。評価会社Irregularが用意した架空企業と同名の実在企業を見つけたり、公開情報から認証情報を得たりしてアクセスした。GoogleによるとGeminiはいずれも実在環境だと認識すると攻撃を自ら停止し、関係企業には通知済みという。

**賛**

事故を隠さず公表し、対象企業への通知と試験手順の修正まで進めた点は重要だ。AIが自律的に止まったことも、安全設計の材料になる。

**ただぁ！**

一番怖いのは「AIが悪意を持った」ことではなく、テストの看板を信じて本物の会社までテスト対象だと思ったこと。賢いエージェントほど、指示の境界が1文字曖昧なだけで行動範囲がインターネット全体になる。

**結論**

モデルの善悪より、サンドボックスと権限設計の問題。AIエージェント時代は「やっていいこと」より「物理的にできないこと」を先に作る必要がある。

### 7．【IT・企業】AnthropicとAccenture、AI評価へ最低20億ドル投資

**何が起きたか**

AnthropicとAccentureは18日、最先端AIモデルを外部の専門家が社内に入り込んで評価する「embedded evaluation」を始めると発表した。Accenture傘下Facultyがレッドチーミング、アラインメント評価、安全策の検証を担当し、両社は今後5年間でそれぞれ最低10億ドル、合計20億ドル以上を投じる見込み。

**賛**

AI企業が自分で「安全です」と採点するだけでなく、外部評価者へ社員に近いアクセスを与える仕組みは一歩前進だ。表面からAPIを叩くだけでは見えない運用や安全策まで確認できる。

**ただぁ！**

外部評価とはいえ、費用は評価される側も出す。監査役を社内へ入れる発想は良いが、本当に厳しい結果をどこまで公開できるかで独立性の価値が決まる。20億ドルの安心料が、20億ドルの身内チェックになったら意味がない。

**結論**

金額より重要なのは、評価者が何を見られ、何を公表できるか。AI安全が理念から監査制度へ移れるかの試金石になる。

**主な参照元：** [Anthropic](https://www.anthropic.com/news/accenture-embedded-evaluation)、[Reuters系報道](https://www.releasetiding.com/business/30765.html)

### 8．【社会・インフラ】キューバで全国停電　今年7回目の大規模グリッド崩壊

**何が起きたか**

キューバの電力網が18日に全面停止し、全国規模の停電が発生した。当局は中部の高圧送電線の障害をきっかけとして復旧作業を開始したが、燃料不足と老朽化した設備が電力システムを不安定にしている。報道では今年7回目の全国的な停電とされる。

**賛**

病院など重要施設を優先しながら段階的に復旧するのは、全面停止後の現実的な対応だ。

**ただぁ！**

ここは生活被害を笑う話ではない。問題は一度の故障より、全国停電が「またか」で処理される頻度になっていること。発電所だけ直しても、燃料・送電網・制裁を含む供給構造が弱いままでは復旧が次の停電までの延命になる。

**結論**

停電の復旧だけでは解決しない。電力インフラを安定させるための燃料確保と設備更新ができるかが本題だ。

**主な参照元：** [Reuters](https://quews.news/cubas-electrical-grid-collapses/)、[DW](https://amp.dw.com/en/cuba-faces-another-nationwide-blackout-amid-us-fuel-blockade/a-79335396)

### 9．【国際・安全保障】米国の台湾向け140億ドル武器売却、承認遅れが企業にも波及

**何が起きたか**

米防衛テック企業Anduril創業者のパーマー・ラッキー氏は19日、台湾向け約140億ドルの武器売却案件をトランプ大統領が承認せず保留していることが、自社の台湾ビジネスにも影響していると明らかにした。トランプ氏は5月の習近平国家主席との会談後、この案件を交渉材料として保留していると説明していた。

**賛**

巨額の武器売却は地域の緊張に直結する以上、政府が外交全体を見ながら承認を判断すること自体は理解できる。

**ただぁ！**

台湾の防衛装備が「交渉カード」になると、抑止力の整備時期まで米中交渉の日程に左右される。兵器企業には商談の遅れでも、台湾側には安全保障の時間そのものだ。

**結論**

売るか売らないかだけでなく、いつ決めるかも政策。来週の米中首脳会談で、この保留がどう扱われるかが焦点になる。

**主な参照元：** [Reuters](https://www.aol.com/articles/defence-firm-anduril-says-us-042610000.html)、[Reuters Connect](https://www.reutersconnect.com/item/anduril-industries-founder-palmer-luckey-speaks-during-an-interview-with-reuters-in-taipei/dGFnOnJldXRlcnMuY29tLDIwMjY6bmV3c21sX1JDMjJNTkFGNjdNRg)

### 10．【経済・企業】Volkswagenが業績見通しを下方修正　Porsche関連などで100億ユーロ負担

**何が起きたか**

Volkswagenは、Porsche株式に関連する評価や人員削減引当金、中国市場の低迷などで約100億ユーロの一時的負担を見込み、業績見通しを引き下げた。18日の欧州市場ではVolkswagen株が5.6％下落し、2025年9月以来最大の下げとなった。Porsche株も4.9％下落した。

**賛**

巨額の費用を先送りせず、事業環境の悪化を見通しへ反映するのは投資家への情報開示として必要だ。人員・事業構造を見直すなら、痛みを数字に出す段階は避けられない。

**ただぁ！**

高級車ブランドを抱えれば利益率も高級になるはずが、今回は関連負担まで高級になった。中国市場の競争激化とEV転換で、昔の「大手だから耐えられる」がそのまま通じなくなっている。

**結論**

100億ユーロは一時費用で片付けるには大きい。次に見るべきは、構造改革後に本業の収益力が戻るかどうかだ。
