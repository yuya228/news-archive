### 1．【経済・暮らし】輸出も輸入も過去最高、それでも6345億円の貿易赤字

**何が起きたか**

財務省が20日に公表した7月の貿易統計で、輸出額は前年同月比23.2％増の11.5兆円、輸入額は27.8％増の12.1兆円となり、いずれも月間として過去最高となった。AIデータセンター向けの半導体関連需要や円安が輸出を押し上げた一方、中東情勢で割高になった原油や米国産原油への切り替えが輸入額を膨らませ、貿易収支は6345億円の赤字だった。原油の輸入量は5.5％増だが、金額は87.8％増えている。

**賛**

輸出が23％伸び、米国向けも中国向けも2割超増えているのは、日本企業が外需を取り込めている証拠。AI関連の設備需要という世界的な追い風を、日本の部品・製造装置がちゃんと売上に変えている。

**ただぁ！**

輸出「過去最高です！」
輸入「こちらも過去最高です！」
収支「赤字です」。

両チーム自己ベストなのに家計簿だけ負けている。しかも原油は量が5.5％増えただけで支払額87.8％増。エネルギー輸入国、日本の弱点が数字であまりにも素直に出た。

**結論**

輸出好調は本物だが、円安とエネルギー高がその稼ぎを吸い取っている。景気にとって大事なのは「売れた額」だけでなく、海外から必要なものをいくらで買わされているか。

### 2．【金融・財政】注目の20年国債入札、平均利回り3.698％　高金利が「実際の値札」になる

**今回の差分**

18日は長期金利上昇と5年債入札、19日は高金利が国の利払い負担へどう波及するかを扱った。20日は、その次の焦点だった20年国債の入札が実際に行われた。

**何が起きたか**

財務省によると、20年国債197回債の競争入札には2兆1190億円の応札があり、5321億円を落札。表面利率は3.7％、平均落札価格に対応する利回りは3.698％だった。世界的な長期債売りが続くなか、米財務省の買い戻し拡大で20日朝には日本の超長期金利もいったん低下していたが、政府が長期で資金を調達するコストの高さそのものは消えていない。

**賛**

高い利回りになれば買い手が現れ、入札そのものが成立する。市場が価格を付けて資金が回ることは、国債市場としては健全な機能でもある。

**ただぁ！**

「金利3％台が怖い」という話をしていたら、20年債の平均利回りは3.698％。2046年まで借りるお金に、もうしっかり高金利の値札が付いている。

政府が景気対策の財布を広げようとする横で、市場は静かに「その借金、前より高くつきますよ」とレシートを伸ばしてくる。

**結論**

高金利はチャート上の警告ではなく、国の資金調達条件そのものになった。これからは日銀の利上げ幅だけでなく、国債費が増える中で政府が何を諦めず、何を削るのかまでセットで見る必要がある。

主な参照元：[財務省・20年国債入札結果](https://www.mof.go.jp/english/policy/jgbs/auction/calendar/eresul/eresul20260820.htm)、[Reuters](https://www.reuters.com/business/bonds-bounce-us-buybacks-relief-may-be-brief-2026-08-20/)

### 6．【宇宙・科学】NASA、Swift宇宙望遠鏡の「救出ミッション」を断念

**何が起きたか**

NASAとKatalyst Space Technologiesは、軌道高度が下がり続けるSwift宇宙望遠鏡をロボット宇宙機LINKで捕獲し、より高い軌道へ押し上げる計画を断念した。NASAはKatalystに3000万ドルを支払い、7月にLINKを打ち上げたが、姿勢制御の不具合で宇宙機が回転。回転速度を落とすことには成功したものの、捕獲に必要な制御を確保できなかった。Swiftは早ければ10月以降に大気圏へ再突入する見通し。

**賛**

20年以上使った衛星を「古くなったから捨てる」ではなく、民間のロボット宇宙機で後から救う挑戦自体には大きな価値がある。成功すれば、将来の衛星延命や宇宙インフラ整備のやり方を変える可能性があった。

**ただぁ！**

沈みかけた衛星を助けるために救助船を打ち上げたら、その救助船の姿勢制御が壊れた。

宇宙版の「レッカー車が現場へ向かう途中で故障」。難易度が高いから笑い話ではないが、3000万ドルかけた実証としては痛すぎる教材になった。

**結論**

失敗したのはSwift救出であって、軌道上サービスという発想そのものではない。LINKは今後も近傍運用の実証を続ける。次のミッションが、この失敗を「3000万ドルの授業料」で終わらせられるかが重要。

### 7．【国際・通商】米加「合意に近づく」、50％関税は延期　でも乳製品の説明が両国で噛み合わない

**何が起きたか**

米国とカナダは、約200億ドル分のカナダ製品に予定されていた追加50％関税を回避するための通商合意に近づいた。関税発動は米東部時間22日午前0時1分まで延期された。トランプ米大統領は米農家へのカナダ関税が「ゼロになる」と主張する一方、カナダ側は乳製品などの供給管理制度は「交渉対象ではない」と明言しており、最終条件はまだ公表されていない。

**賛**

発動直前に関税を止め、交渉を続ける方が、実際に50％を掛け合って企業と消費者へコストを押し付けるよりはるかにまし。両国は経済的に深く結び付いており、予見可能性を戻す意味は大きい。

**ただぁ！**

米国「農業関税はゼロになります」
カナダ「供給管理は守ります」
双方「良い合意です」。

まだ完成していない契約書を、両者が別々の完成版として説明している。外交の「大筋合意」、だいたい細字のところが本編。

**結論**

関税延期は成功だが、合意成立とはまだ言えない。乳製品アクセス、酒類規制、具体的な関税撤回範囲が同じ文書で確認できて初めて「決着」と呼べる。

### 8．【金融・財政】米財務省、長期国債買い戻しを倍増　「火消し」はしたが借金は消えない

**何が起きたか**

米財務省は、10～30年の国債を市場から買い戻す1回当たりの規模を20億ドルから少なくとも40億ドルへ倍増すると発表した。9月9日から11月4日まで適用する。長期金利の急上昇で30年債利回りが一時5.34％と2007年以来の高水準に達したことを受けた措置で、発表後は利回りが低下した。ただし米国の公的債務残高は40兆ドルを突破している。

**賛**

市場の流動性が細り、長期金利が急騰すると住宅ローンや企業融資まで一気に高くなる。財務省が市場機能を支えるため買い戻しを増やすこと自体には合理性がある。

**ただぁ！**

40億ドルに倍増、と聞くと巨大だが、米国債市場は約32.2兆ドル。プールにバケツを2杯から4杯に増やした感じである。

しかも金利上昇の根っこは、財政赤字と40兆ドルを超えた債務への不安。買い戻して時間は買えても、借金そのものは買い戻せていない。

**結論**

短期の市場安定策としては効いたが、長期金利を本当に抑えたいなら本丸は財政とインフレ。市場介入が恒例行事になった瞬間、「非常手段」ではなく政策依存になる。
