### 1．【暮らし・IT】ドコモがRCS開始　標準メッセージが進化、でもSMS課金ガチャは残る

**何が起きたか**

NTTドコモは24日、新しいメッセージサービス「RCS」の提供を開始した。Android 10以降の対応端末では、電話番号を使って高画質な写真・動画や既読表示などを利用できる。RCS同士の送受信は無料だが、相手がRCS非対応などでSMSに切り替わった場合はSMS料金が発生することがある。iPhoneへの提供時期は後日案内するとしている。

**賛**

電話番号だけで画像も長文も送りやすくなり、OSをまたいだ標準メッセージがようやく現代化する。特定アプリを入れているかどうかに左右されにくいのは、地味だがかなり大きい。

**ただぁ！**

ただぁ！ 「次世代メッセージです」と言いながら、相手の環境次第で裏からSMS料金が生えてくるのは少し古代文明が残っている。LINEに勝てとは言わんから、せめて送信ボタンを押す前に「これは無料」「これは有料」が一発で分かる世界にしてくれ。

**結論**

RCS自体は歓迎。ただ、通信の進化で一番消してほしいのは機能不足より料金の分かりにくさ。次世代を名乗るなら、請求画面まで次世代で頼む。

主な参照元：[NTTドコモ・提供開始案内](https://www.docomo.ne.jp/info/notice/page/260513_00.html)、[NTTドコモ・RCSサービス](https://www.docomo.ne.jp/service/rcs/)

### 2．【政治・外交】超党派議員団が北京へ　日中の公式回線が細りすぎて「議員外交」で再接続

**何が起きたか**

自民党の橋本岳氏や公明党、中道改革連合の議員ら超党派の議員団が24日、中国共産党関係者との会談のため北京へ向かった。高市早苗首相の台湾有事を巡る発言後に日中関係が悪化して以来、こうした議員交流は初めて。訪問は27日までで、経済面にも波及した緊張の中、対話の糸口を探る。

**賛**

関係が悪い時ほど、話せる窓口は多い方がいい。政府同士が硬直しているなら、議員外交で別回線を残すのは安全弁になる。仲良くするためというより、誤解でさらに壊さないための通信路だ。

**ただぁ！**

ただぁ！ 「政府間の連絡が切れてきたので議員団が北京へ行きます」という時点で、外交インフラとしてはだいぶWi-Fi一本線。首脳が強い言葉を投げた後、別の人たちが黙々と回線復旧する構図、毎回やるにはコストが高すぎる。

**結論**

対話再開は必要。ただし議員団を消火器として使い続けるより、政府同士が常時つながる回線を戻す方が先。外交まで「一回再起動してみますか」で済ませたくない。

主な参照元：[AP](https://apnews.com/article/japan-china-takaichi-taiwan-f8d51071001799e9499f47f4b6f48e92)、[The Japan Times](https://www.japantimes.co.jp/news/2026/08/19/japan/japan-lawmaker-group-china/)

### 3．【社会・防災】台風18号が南西諸島へ　強い勢力で接近、橋や道路の通行止めにも警戒

**何が起きたか**

非常に強い台風18号は24日、日本の南を進み、25〜27日に強い勢力で南西諸島へ接近する見込みとなった。気象庁は沖縄で高波や暴風への警戒を呼びかけ、沖縄県も風雨の状況によって橋や道路が通行止めになる可能性を案内している。台風は速度を落とす見込みで、影響が長引く恐れもある。

**賛**

接近前から道路・橋の閉鎖可能性まで具体的に出しておくのは大事。「台風が来ます」だけより、何が使えなくなるかが分かる方が予定を早く変えられる。

**ただぁ！**

ただぁ！ 台風情報を見るたびに「まだ遠いから大丈夫」が一番危ない。沖縄の台風、距離感だけ見ていると翌日に交通網ごと予定を没収してくる。観光日程は気合で守れても橋は気合で開かない。

**結論**

今回は進みが遅く、長期戦になり得る。旅行も生活も「行けるか」より「戻れるか」まで見て判断した方がいい。

主な参照元：[共同通信](https://kumanichi.com/articles/2028195)、[沖縄県](https://www.pref.okinawa.jp/machizukuri/doboku/1013804/1025189/1040104.html)

### 4．【政治・地域】福岡市・高島市長が5選不出馬　4期16年で「多選の弊害」を語る

**何が起きたか**

福岡市の高島宗一郎市長は24日、次の市長選に立候補せず、現在の4期目で退任する意向を正式に表明した。2010年に36歳で初当選し、再開発や国家戦略特区などを進めてきた。会見では「次の世代にたすきをつなぎたい」とし、多選による弊害にも触れた。

**賛**

長期政権は意思決定が安定する一方、どこかで交代しないと行政も人脈も固定化しやすい。自分で区切りをつけ、次の世代へ渡す判断は健全だ。

**ただぁ！**

ただぁ！ 4期16年やった人から「多選の弊害もあります」と言われると、ラーメン4杯食べた後に「塩分は控えた方がいいですね」と健康指導されてる感じはある。正しい。正しいけど、だいぶ満腹になってから言う。

**結論**

16年で街がどう変わったかは選挙で検証されるべきだが、席を永久指定席にしなかったのは評価できる。次は「高島市政の続き」ではなく、何を変えるかで争ってほしい。

主な参照元：[KBC九州朝日放送](https://kbc.co.jp/gyutto/detail.php?cdid=47142)、[共同通信](https://kumanichi.com/articles/2028223)

### 5．【暮らし・AI】奈良市、相談窓口に24時間生成AI　「いつでも寄り添う」の中身はAIが夜勤

**何が起きたか**

奈良市は24日、DVや性被害、家庭・人間関係などを相談できる「わたしのミカタ相談」で、LINEを使った24時間の生成AIチャットを9月から始めると発表した。市内在住・在勤・在学者が対象で性別を問わない。必要に応じて専門相談員へつなぎ、夜間に深刻な内容があった場合は翌朝に人が確認する運用も示している。

**賛**

人に電話するほど整理できていない段階でも、深夜に一度言葉へ出せる入口は価値がある。若い世代ほど電話窓口を避ける傾向があるなら、LINEに入口を置くのも合理的だ。

**ただぁ！**

ただぁ！ 行政が「24時間寄り添います」と言った結果、人間は寝てAIだけ夜勤してるの、令和の福祉が急にSFである。深刻案件を翌朝に人が見るなら、AIを「相談員」と盛るより「夜間の受付と整理役」と正直に言った方が期待値事故が少ない。

**結論**

AI相談は入口としては面白い。でも危機対応までAIに任せた気になった瞬間に危ない。24時間開いていることと、24時間人が助けられることは別物だ。

主な参照元：[奈良市プレスリリース](https://prtimes.jp/main/html/rd/p/000000465.000036429.html)、[奈良市](https://www.city.nara.lg.jp/site/press-release/273514.html)

### 6．【暮らし・IT】NZ首相が16歳未満SNS禁止法案　なお連立相手2党が反対

**何が起きたか**

ニュージーランドのラクソン首相は24日、16歳未満のSNS利用を禁止する法案を発表した。Instagram、TikTok、Snapchat、Facebookなどに年齢確認を求め、違反企業には世界売上高の最大10％の罰金を科す案。一方、連立政権を組むACT党とNZファーストは反対しており、現時点では可決に必要な支持が足りない。

**賛**

子どものSNS依存や有害コンテンツへの対策を「家庭で頑張って」で丸投げせず、プラットフォーム側にも責任を負わせる発想は分かる。罰金が売上高連動なのも、大手企業にとって無視できる小銭にしない工夫だ。

**ただぁ！**

ただぁ！ 首相が「子どもをSNSから守る法案です」と出したら、まず同じ政府の仲間2党から「いや通しません」が返ってくる。家族会議を始める前に校則を印刷して全校配布したみたいな順番である。しかも年齢確認を厳しくするほど、今度は全員が顔やIDを出すプライバシー問題が育つ。

**結論**

SNSの年齢規制は世界的に広がっているが、禁止ボタン一個で解決する話ではない。子どもを守る仕組みが、大人まで常時本人確認される仕組みに化けないかが次の争点だ。

### 7．【IT・科学】Xiaomiが自社スマホチップ「Xring O3」　設計は自前、製造はTSMC 3nm

**何が起きたか**

Xiaomiは24日、自社開発のスマートフォン向けSoC「Xring O3」を発表した。Reutersによると、製造はTSMCの3nmプロセスで、今後の旗艦折りたたみスマホに搭載され、20万〜30万個の出荷を目指す。XiaomiはAI処理向けのXring O100、自動運転向けD100もTSMCへ製造委託するとしている。

**賛**

AppleやSamsungのように端末とチップを一体設計できれば、性能・消費電力・機能の最適化を自社で回しやすい。QualcommやMediaTekへの依存を減らす意味もある。

**ただぁ！**

ただぁ！ 「自社チップで供給網を自立」と言いつつ、最先端3nmを焼く厨房はTSMC。レシピは自作したけど、超一流レストランの厨房を台湾から借りている状態である。半導体の自前化、どこまで行っても製造装置とファウンドリーというラスボスが残る。

**結論**

O3はXiaomiの技術力を示す一歩。ただ本当の勝負は「作れた」ではなく、何百万台規模で安定して載せ、電池持ちや性能で既存SoCに勝てるかだ。

**結論**

現段階では起訴であり、有罪が確定したわけではない。ただ、AI半導体の管理は「売った会社」だけでなく物流・社員・仲介まで見る時代に入っている。

### 9．【国際・安全保障】EU、ウクライナ防衛に追加61億ユーロ　金は出せても迎撃弾は印刷できない

**何が起きたか**

欧州委員会は24日、ウクライナが防空システム、ミサイル、弾薬、レーダーなどを調達するための追加61億ユーロの資金支援を承認した。EUによると、これまで承認済みの160億ユーロの調達計画に上乗せするもので、そのうち83.5億ユーロはすでに支出されている。

**賛**

ロシアの攻撃が続く中、防空や弾薬の不足を資金面で支えるのはウクライナの防衛継続に直結する。単なる声明より、調達に使える金を出す方が実務的だ。

**ただぁ！**

ただぁ！ 戦争支援は金額を積むと仕事した感が出るが、61億ユーロを承認しても迎撃ミサイルがプリンターから出てくるわけではない。生産能力、納期、在庫が詰まれば予算は立派な予約券になる。

**結論**

支援額より次に見るべきは、何を何基・何発、いつ届けられるか。戦場では予算書より納期表の方が強い。

### 10．【経済・国際】米加通商、4日前の「合意接近」から崩壊　米50％関税、カナダも報復へ

**今回の差分**

20日は、米国がカナダへの追加50％関税を延期し、交渉が合意へ近づいている流れを扱った。それが数日で反転。交渉は決裂し、米国は約200億ドル相当のカナダ製品へ50％関税を発動、カナダも9月8日から同額規模の報復関税を実施すると表明した。

**何が起きたか**

カナダのカーニー首相は、米国側が最終局面でカナダの第三国との通商協定を制約する内容を求めたとして受け入れを拒否した。米通商代表部は逆に、カナダ側が新たな要求を持ち出して約束から後退したと主張している。両国の説明は真っ向から食い違い、追加措置の応酬も示唆されている。

**賛**

カナダ側が「関税を下げてもらう代わりに将来の通商政策まで縛られる」条件を主権の問題として拒む理屈は分かる。目先の損失だけで長期の裁量を売らない判断だ。

**ただぁ！**

ただぁ！ 4日前に「合意へ接近」だった話が、週明けには50％関税と報復関税。通商交渉、進捗バーが95％まで行って突然アンインストール始めるのやめてくれ。企業はその間ずっと在庫と価格を現実の金で調整している。

**結論**

今回の反転は、関税交渉の「ほぼ合意」がほぼ何の保証にもならないことを見せた。次に必要なのは威勢のいい数字ではなく、企業が半年先の価格を決められる程度の予測可能性だ。

主な参照元：[AP](https://apnews.com/article/canada-carney-trump-tariffs-economic-coercion-trade-a180ac85a70bbfb512ea59c224cb6c31)、[Reuters](https://www.reuters.com/business/dollar-trading-near-multi-month-lows-restrained-by-debt-nerves-2026-08-24/)
