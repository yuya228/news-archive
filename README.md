### 2．【社会・安全】警察、犯罪グループのスマホ通信を遠隔確認する制度を検討

**何が起きたか**

**賛**

海外の指示役から実行犯へ命令が飛ぶ犯罪では、事件後の捜査だけでなく被害を未然に防ぐ手段が必要になる。

**結論**

必要性はある。だからこそ、権限と同じ強さのブレーキを制度に組み込むべきだ。

### 7．【医療・暮らし】米FDA、週1回の基礎インスリン「Onswik」承認

**何が起きたか**

米FDAは24日、イーライリリーの2型糖尿病向け基礎インスリン「Onswik」を承認した。1日1回型に比べ年間300回超の注射を減らせる。3400人超を対象とした第3相試験で、血糖管理効果は比較対象の毎日投与型に対して非劣性だった。

**賛**

慢性疾患では薬が効くだけでなく、続けやすさが重要だ。毎日から週1回への変化は管理負担を大きく減らす。

**ただぁ！**

回数が減っても投与管理が雑でよくなるわけではない。1型糖尿病には使えず、低血糖などへの注意も必要だ。

**結論**

医療の進歩は「日常の面倒を300回減らす」という形でも効いてくる。
