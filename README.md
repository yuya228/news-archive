### 2．【経済・市場】日経平均、一時1100円超安　終値は396円安まで戻す

**何が起きたか**

29日の東京株式市場で日経平均は続落した。前場は570円安、一時は800円超下落し、後場には下げ幅が1100円を超える場面もあった。終値は前日比396円35銭安の6万5481円27銭。9月末の配当権利落ちに加え、原油高や金利上昇、前日の米株安が重しとなった。

**賛**

一時1100円以上落ちても、引けでは400円弱まで戻した。全部が景気悪化を織り込んだ売りではなく、配当落ちなど機械的な下押しも混ざっていると分けて見る必要がある。

**ただぁ！**

とはいえプライム市場では値下がり銘柄が1300を超えた。指数だけ見て「結構戻ったやん」で済ませると、持ってる株だけ全然戻ってない現象が普通に起きる。

**結論**

「600円安」だけで切り取るより、一時1100円安から396円安まで戻した一日の値動きそのものが本題。原油と金利が落ち着かなければ、まだ市場の床は動く。

### 4．【暮らし・消費】卵1パック309円で過去最高　年末まで高値続く見通し

**何が起きたか**

農林水産省の価格調査で、全国のスーパーなどにおける卵1パックの平均小売価格が309円となり過去最高水準となった。日本養鶏協会は、生産が回復しつつある一方、冬は鍋物やクリスマス向け需要が増えるため、年末まで高値が続くとの見通しを示している。

**賛**

昨シーズンの鳥インフルエンザから生産自体は回復方向。2027年前半に向けて供給量が増える見通しもあり、永遠に309円コースと決まったわけではない。

**ただぁ！**

卵、昔は「とりあえず冷蔵庫に入れとく安い食材」代表やったのに、309円で過去最高。月見商戦、おでん、ケーキと需要イベントも待ち構えていて、年末まで休ませてくれない。

**結論**

卵の値段は家計への体感がでかい。数十円の差でも毎週買えば効いてくるので、「物価上昇率何％」より冷蔵庫の方がインフレを分かりやすく教えてくれる。

### 8．【IT・規制】Google、EUのDMA命令を提訴　AIと検索データ開放を巡り対立

**何が起きたか**

Googleは、EUのデジタル市場法（DMA）に基づく二つの命令についてEU一般裁判所へ異議を申し立てた。EUは、Android上で競合AIサービスへ機能を開放することや、一定の匿名化を施した検索データを競合検索サービスや検索機能を持つAIへ提供するよう求めている。

**EU側の主な論点**

欧州委員会は、Googleが長年蓄積してきた検索データやAndroid機能へのアクセス格差を小さくし、検索やAIで競争できる環境を作ることがDMAの目的だとしている。検索データについては匿名化手順も定めている。

**Google側の主な論点**

Googleは、競合へのデータ・機能開放を義務付けることでプライバシーやセキュリティ上のリスクが生じると主張している。特に検索履歴などの扱いについて、EUの要求が利用者へ取り返しのつかない影響を与える可能性があるとしている。

**現時点の整理**

論点は単純な「Google独占けしからん」対「EU規制しすぎ」ではない。競争相手へどこまでデータを渡せば公平になり、どこからユーザーのプライバシーを削るのか、その境界を裁判所でも争う段階に入った。

**主な参照元**：  
[欧州委員会](https://digital-markets-act.ec.europa.eu/commission-provides-guidance-google-ai-interoperability-android-and-sharing-google-search-data-under-2026-07-16_en?prefLang=et)

**結論**

29日は「洪水そのもの」から「洪水の後始末」へニュースの焦点が移った日。都市災害は水が引いてからの方が請求書が多い。
