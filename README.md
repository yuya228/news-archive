### 1．【企業・会計】ニデック、新社長会見でも「監査意見」が宿題のまま

**今回の差分**

9月29日時点では岸田光哉社長の辞任方向が中心だったが、今回は戒田理夫新社長の会見と監査法人の説明で、「決算を正常化できるか」が具体的な焦点になった。

**何が起きたか**

ニデックは2026年3月期に6320億円超の減損を計上し、最終損益は5646億円の赤字となった。PwCジャパン監査法人は十分な監査証拠を得られず監査意見を不表明。1日の会見で戒田新社長は、まず適正な決算を出せる状態へ戻すことを優先すると説明し、会社と監査法人は10月中の監査意見取得を目指している。

**賛**

数字を出し直し、監査法人も会社も残った問題を表に出している点は、信頼回復の最低条件ではある。

**ただぁ！**

6320億円超の減損も重いが、さらに重いのは監査法人が「判断できるだけの証拠が足りない」としていること。赤字額が出ても、会社の数字を安心して読める状態へ戻ったとはまだ言えない。

**結論**

前回の「トップ交代より内部統制が本番」が、そのまま次の宿題になった。10月中に監査意見を得られるかが最初の答え合わせになる。

**主な参照元**：[ニデック](https://www.nidec.com/en/corporate/news/2026/news0930-02/) / [Reuters](https://www.reuters.com/world/asia-pacific/nidec-aims-october-audit-sign-off-new-ceo-vows-restore-trust-2026-10-01/)

### 2．【暮らし・物価】10月の食品値上げ3153品目　2カ月連続3000超

**何が起きたか**

10月に値上げ予定の飲食料品は、主要195社で3153品目に上った。帝国データバンクによると、2カ月連続で3000品目を超えるのは2023年6〜7月以来。酒類・飲料が1399品目で最多、調味料は820品目。2026年通年で判明している値上げは2万187品目となり、2年連続で2万品目を超えた。

**賛**

原材料だけでなく、物流、エネルギー、包装資材、人件費までコスト上昇が広がっており、企業側にも吸収し切れない負担が積み上がっている。

**ただぁ！**

「3153品目」と聞いても、家計側は結局いつもの商品が何円になったかをレシートで知るしかない。物価統計より先に、買い物かごが説明会を始める。

**結論**

秋の値上げは一発ではなく連打。節約術を増やす前に、普段買う定番品の価格そのものを一度見直した方が現実的な局面になっている。

**主な参照元**：[帝国データバンク](https://www.tdb.co.jp/report/economic/20260930-pricepass-on202609/) / [TBS NEWS DIG](https://newsdig.tbs.co.jp/articles/-/2980536)

### 3．【AI・電力】JERA×Dell×RHAELM、千葉で400MW級AIデータセンター計画

**何が起きたか**

JERA、Dell Technologies、RHAELMは、日本で大規模AIインフラを共同開発する覚書を締結した。第1号案件はJERA千葉火力発電所周辺で、400MW級のAIデータセンターを計画。Reutersによると投資規模は150億ドルで、2028年から段階稼働、2029年の全面稼働を想定する。JERAが長期契約で電力を供給する。

**賛**

AI計算能力を増やす最大の壁の一つは電力。発電設備、電力、冷却、計算基盤を一体で設計し、系統接続待ちや個別設計の長期化を減らす発想はかなり現実的だ。

**ただぁ！**

「クラウド」と呼ぶと軽そうだが、400MW級まで行くと実態は巨大インフラ事業。AIモデルの競争が、とうとう土地・発電所・送電・冷却設備の確保競争まで降りてきた。

**結論**

AI競争は性能表だけでは終わらない。次のボトルネックは「何MWを、何年待たずに用意できるか」。生成AIの裏側、思ったより発電所である。

**主な参照元**：[JERA](https://www.jera.co.jp/news/information/20261001_2535) / [Reuters](https://www.reuters.com/business/energy/jera-teams-up-with-dell-rhaelm-ai-infrastructure-development-japan-2026-10-01/)

### 4．【エンタメ・企業対応】timelesz、7人体制へ　STARTOが猪俣周杜氏との契約解除

**何が起きたか**

STARTO ENTERTAINMENTは、timeleszの猪俣周杜氏との専属契約を9月30日付で解除したと1日に発表した。会社は本人への聞き取りと事実確認を行い、契約上の重大な違反が解除事由に当たると判断したとしている。猪俣氏は処分保留で釈放され捜査中で、刑事上の処分は確定していない。グループは7人で活動を継続する。

**賛**

会社が刑事処分とは別に「専属契約上の判断」と位置付け、残る7人に処分責任を負わせるものではないと明記したのは、責任範囲を整理するうえで重要だ。

**ただぁ！**

事件が起きると、関与していないメンバーや被害者までSNSで説明責任を背負わされがちになる。公式発表以上の事情を想像で埋める段階ではない。

**結論**

確定しているのは契約解除と7人体制への移行まで。刑事上の評価は捜査の結論を待ち、グループは今ある仕事で信頼を積み直していくことになる。

**主な参照元**：[STARTO ENTERTAINMENT](https://corporate.starto.jp/s/e/news/detail/10080) / [ORICON NEWS](https://www.oricon.co.jp/news/2483715/full/)

### 6．【AI・半導体】Tencent、Oracle経由でAIチップ約10万基を海外利用へ

**何が起きたか**

中国Tencentが米Oracleと契約し、中国国内では入手困難な先端AIチップ約10万基を東南アジアのOracleデータセンターで利用する計画だとFinancial Timesが報じ、Reutersも伝えた。契約は5年間で約70億ドル規模とされる。米国の先端半導体輸出規制が続くなか、中国企業が「チップを輸入する」のではなく海外クラウドで計算能力を借りる動きが広がっている。

**賛**

企業側から見れば、必要なのはGPUを所有することより計算能力を確保すること。クラウド経由なら大規模AI開発を止めずに済む。

**ただぁ！**

半導体規制の地図は国境線だけでは足りなくなった。チップが中国に入らなくても、中国企業の処理が海外のGPUへ飛んでいけば、規制とクラウド利用の境界は一気に複雑になる。

**結論**

AI競争では「どのチップを持っているか」から「世界のどこで計算できるか」までが戦略になった。GPU不足、とうとう住所まで重要である。

**主な参照元**：[Reuters](https://www.reuters.com/world/china/chinas-tencent-leases-100000-chips-oracle-accelerate-ai-push-ft-reports-2026-10-01/) / [Financial Times](https://www.ft.com/content/8799b33d-f07c-4a03-82f0-bf5d3d1d29e9)

### 7．【暮らし・決済】豪州、カード決済の上乗せ手数料を原則禁止

**何が起きたか**

オーストラリアでは1日から、Visa、Mastercard、eftposなど主要カードの決済時に店舗がカード利用を理由として追加手数料を載せる仕組みが原則使えなくなった。RBAは同時に国内カードのインターチェンジ手数料上限も引き下げた。Reutersによると、カード上乗せは年間16億豪ドル超に相当し、一方で一部の小規模飲食店などは決済コストを商品価格へ織り込む動きを見せている。

**賛**

RBAは、支払時になって追加料金が出るより、決済コストを表示価格へ含めた方が消費者に分かりやすく、手数料引き下げと合わせて競争を促せるとしている。

**ただぁ！**

一方、小規模事業者にはカード処理費そのものが消えるわけではないとの声がある。別建て手数料を消しても、その分が商品価格へ移れば「コスト消滅」ではなく「置き場所変更」になる。

**結論**

1日から変わったのは、まず請求の見え方。実際の負担が下がるかは、引き下げられた決済手数料と店舗価格の両方を見る必要がある。

**主な参照元**：[Reserve Bank of Australia](https://www.rba.gov.au/payments-and-infrastructure/review-of-retail-payments-regulation/2026-03/conclusions-paper/faqs/) / [Reuters](https://www.reuters.com/world/asia-pacific/australian-businesses-raise-prices-card-surcharge-ban-takes-effect-2026-10-01/)

### 8．【経済・市場】米10年債5.34％、2002年以来の高水準　世界で国債売り

**何が起きたか**

世界の国債市場で売りが強まり、米10年国債利回りは1日に5.34％台まで上昇し、2002年以来の高水準となった。Reutersによると、フランス10年債は5％近辺、英国30年債は6％を超え、日本でも国債利回り上昇が続く。高いエネルギー価格やインフレ懸念、政府債務への警戒が重なり、株式や社債市場にも圧力が波及した。

**賛**

債券市場がインフレや財政リスクを金利へ織り込むのは本来の価格発見でもある。借り手にとって厳しい数字でも、リスクが見えないふりをするよりは市場として正直だ。

**ただぁ！**

国債金利が上がれば、政府だけの話では終わらない。住宅ローン、企業融資、株の評価まで同じ金利の物差しに引っ張られる。安全資産が荒れると、ほかの資産まで落ち着かない。

**結論**

5.34％は金融市場の一数字ではなく、世界中の「借りる値段」の基準。AI景気が強くても、金利の請求書は別便で届く。

**主な参照元**：[Reuters](https://www.reuters.com/business/bonds-teeter-after-us-treasuries-worst-quarter-since-1994-2026-10-01/) / [U.S. Department of the Treasury](https://home.treasury.gov/resource-center/data-chart-center/interest-rates/TextView?field_tdr_date_value=2026&type=daily_treasury_yield_curve)

### 9．【スポーツ】ヤンキース、宿敵レッドソックスを2連勝でスイープ

**何が起きたか**

MLBア・リーグのワイルドカードシリーズで、ヤンキースがレッドソックスを9-2で破り、2連勝で地区シリーズ進出を決めた。6回に一挙6点を奪い、コディ・ベリンジャーが3ランを含む4打点。先発マックス・フリードは6回1失点だった。主将アーロン・ジャッジを右ふくらはぎ痛で欠く中でも、2試合合計18得点で押し切った。

**賛**

短期決戦で主砲不在は普通ならかなり痛い。それでも先発投手と打線全体で穴を埋め、宿敵相手に2試合でシリーズを終わらせた。

**ただぁ！**

レッドソックス側からすれば、最大の問題は「ジャッジがいなかったのに普通に18点取られた」こと。相手の弱点を待っていたら、弱点以外が全部殴ってきた。

**結論**

ヤンキースは次のレイズ戦へ。主力復帰を待ちながら勝ち上がれるなら理想形だが、ここから相手も一段強くなる。

### 10．【気候・環境】ギリシャのコロニア湖、10年で水面が10分の1未満に

**何が起きたか**

ギリシャ北部のコロニア湖が、長期の少雨、灌漑用水の過剰利用、気温上昇の影響で急激に縮小している。Reutersが国立アテネ天文台の衛星データとして伝えたところでは、水面積は2016年の34.4平方kmから2026年には2.7平方kmまで減少。かつて渡り鳥や漁業、観光を支えた湿地は、浅い水たまりとひび割れた湖底が目立つ状態になった。

**賛**

衛星観測で水面積を継続的に追えるため、「なんとなく干ばつが深刻」ではなく、変化を数字で捉え、取水管理や保全策の効果を検証できる。

**ただぁ！**

気候変動だけに全部を押し付けると話を外す。少雨と高温に、人間の灌漑利用が重なった複合問題で、水が減って農業が苦しくなるほどさらに水を使いたくなる悪循環がある。

**結論**

34.4から2.7平方km。気候問題は将来予測だけではなく、すでに地図の水色そのものを書き換えている。

**主な参照元**：[Reuters](https://www.reuters.com/sustainability/cop/greeces-vanishing-lake-exposes-rapid-impact-climate-change-2026-10-01/) / [eKathimerini](https://www.ekathimerini.com/news/environment/1315862/former-large-lake-east-of-thessaloniki-now-a-borderline-swamp/)
