### 1．【暮らし・エネルギー】来月の電気・ガス、大手14社すべて値上がり　補助縮小と資源高が同時パンチ

**何が起きたか**

大手電力10社と都市ガス大手4社の来月の料金が、そろって前月より上がる。標準家庭の電気料金は252～509円上昇し、東京電力は432円増の8275円。都市ガス4社も237～307円上がる。中東情勢を背景に燃料価格が上がる一方、政府の料金支援も縮小するためだ。東京ガスも10月検針分について、標準家庭で9月検針分より307円高い5744円としている。

**賛**

燃料価格の変化を料金へ反映する仕組み自体は必要だし、これまで補助が急騰のクッションになってきたのも事実。市場価格を永久に見なかったことにするわけにはいかない。

**ただぁ！**

ただぁ！ 資源価格が上がるタイミングで補助も薄くなるから、家計には「相場高」と「支援縮小」が同時に来る。支援を終える時期に中東情勢が空気を読んでくれるわけではない。

**結論**

値上げの理由を電力・ガス会社だけに押しつけると半分しか見えない。今回の請求書は、燃料市場と補助金設計の共同制作だ。

主な参照元：[FNNプライムオンライン](https://www.fnn.jp/articles/-/1103321)、[東京ガス](https://www.tokyo-gas.co.jp/news/press/20260828-02.html)

### 2．【政治・経済】高市首相、27年度の新規国債「40兆円程度」に抑制へ　ただし今年度32.7兆円よりは増える

**何が起きたか**

高市早苗首相は読売新聞のインタビューで、2027年度の新規国債発行額を40兆円程度に抑える考えを示した。2026年度当初予算の新規国債発行額は32.7兆円。各省庁の27年度予算概算要求は130兆円を超える見通しで、政府は補正予算で計上してきた一部経費を当初予算へ移すことも検討している。

**賛**

最初から発行額の目安を置き、財政規律を意識させる意味はある。景気対策だからと青天井にするより、どこまで借金で賄うかを先に示す方が議論はしやすい。

**ただぁ！**

ただぁ！ 「40兆円程度に抑えます」は節約感のある日本語だが、今年度の32.7兆円より数字は大きい。天井を付けました、なお天井は去年より高くしました、では見出しだけ読むと印象が逆になる。

**結論**

見るべきは「40兆円以内」という響きではなく、何へ使い、成長と税収でどう返すか。財政規律は上限の名前ではなく中身で採点される。

主な参照元：[Reuters](https://www.reuters.com/world/asia-pacific/japan-aims-cap-fy27-new-bond-issuance-40-trillion-yen-pm-says-yomiuri-interview-2026-08-28/)、[読売新聞報道](https://news.livedoor.com/article/detail/32178094/)

**結論**

失セット0は強さの証明。でも29日はその証明書を受付で出しても1点もくれない。五輪切符まで、あと2試合が急に重い。

### 4．【社会・環境】水島港でヒアリ3,000匹超　女王アリと卵・幼虫まで確認

**何が起きたか**

環境省は28日、岡山県倉敷市の水島港で特定外来生物のヒアリが確認されたと発表した。働きアリは3000匹超、羽アリ約100匹に加え、女王アリ1匹と多数の卵・幼虫・さなぎも見つかった。周辺には殺虫餌を設置し、引き続き調査と防除を進める。人的被害は確認されていない。

**賛**

港湾調査で見つけ、専門家確認から防除まで早く動けているのは重要。侵入を完全にゼロにできないなら、定着前に見つけて潰す体制の方が現実的だ。

**ただぁ！**

ただぁ！ 「3000匹」という数も怖いが、話を重くしているのは女王アリと卵・幼虫までいたこと。旅行者が数匹迷い込んだ話ではなく、繁殖まで進んでいた可能性を見ないといけない。

**結論**

3,000匹駆除して終わりではない。女王と次世代まで見つかった以上、周辺監視を続けて「残りゼロ」を確認するところまでが仕事だ。

### 5．【暮らし・IT】KDDI、自動運転バスの通信をAIで自動最適化へ　9月から日立市で実証

**何が起きたか**

KDDIとみちのりホールディングスは、9月1日から茨城県日立市で自動運転バス向け通信の実証を始める。複数のAIエージェントが基地局の無線設定を自動調整し、5Gの接続性や通信品質が改善するか、ネットワーク設計・調整の作業を減らせるかを検証する。自動運転では遠隔監視などに安定した通信が必要になる。

**賛**

自動運転は車載AIだけ賢くしても成立しない。遠隔監視や映像伝送が前提なら、道路と同じくらい通信インフラを安定させる必要があり、そこを自動最適化するのは実務的だ。

**ただぁ！**

ただぁ！ 「無人運転」と聞くと人が消えたように見えるが、実際には遠隔監視、通信運用、基地局調整へ仕事の場所が移る。ハンドルから人を降ろしても、管制室とネットワークまで無人になるわけではない。

**結論**

自動運転の本体を車だけだと思うと半分しか見えない。道路の次に、通信が「止まったら走れないインフラ」になる。

主な参照元：[KDDI](https://newsroom.kddi.com/news/detail/kddi_nr-1126_4672.html)、[Impress AI Watch](https://ai.watch.impress.co.jp/docs/news/2136524.html)

### 6．【IT・安全保障】米裁判所、国防総省のAnthropic排除を差し止め　軍事AIの利用条件が法廷へ

**何が起きたか**

米連邦地裁は28日、国防総省がAI企業Anthropicをサプライチェーン上のリスクとして指定し、政府契約から事実上排除する措置を差し止めた。争いの発端は、Anthropicが自社AIを無制限の軍事監視や自律兵器に使うことを認めなかったこと。リタ・リン判事は、国防総省側の指定や対応に法的な問題があると判断した。訴訟は続く。

**賛**

軍事利用の境界を企業がどこまで設けられるのか、政府がどこまで調達条件で押せるのかは、裁判で手続きを踏んで線を引く価値がある。安全保障を理由にすれば何でも即決、では民主国家の仕組みとして雑すぎる。

**ただぁ！**

ただぁ！ 契約条件の対立が、そのまま「安全保障上のサプライチェーンリスク」というラベルに化けるなら、調達権限が巨大な圧力装置になる。裁判所が止めたのは、AIの善悪よりその手続きの飛ばし方だ。

**結論**

これはAnthropicの利用規約が最終勝利した判決ではない。軍事AIの線引きを誰が、どんな手続きで決めるのか。そのルール作りが法廷へ持ち込まれた。

主な参照元：[Reuters](https://www.reuters.com/legal/government/us-judge-blocks-pentagons-anthropic-blacklisting-2026-08-28/)、[AP](https://apnews.com/article/f15e3c30186385e73e72bee82d85b05c)

### 7．【国際・エネルギー】ホルムズ再開交渉、イランが条件案作成へ　でも実際の通航は7隻に後退

**今回の差分**

27日は、コモディティ船の通航が8隻から10隻へ増えた一方、タンカーが飛翔体に当たり火災を起こしたことを扱った。28日は再開交渉が具体化し、イランが海峡再開の条件案をまとめる方向へ進んだ一方、通航数は暫定集計で7隻へ減った。

**何が起きたか**

カタールなどの仲介を受け、イランはホルムズ海峡の再開条件を整理する意向を示した。イランとオマーンによる一時航路の協議も続いている。ただ、Kplerの暫定データでは27日のコモディティ船通航は7隻で、前日の17隻、10日平均の約15隻を下回った。米国とイランの要求にはなお隔たりがある。

**賛**

「再開したい」という抽象論から、条件を紙に落とす段階へ進むのは前進。恒久合意が遠くても、航路の安全確保だけ先に切り出せれば世界経済への効果は大きい。

**ただぁ！**

ただぁ！ 会議室では航路再開の条件が具体化している横で、実際に通る船はまた減っている。外交の進捗率と海上の安心度が同じグラフで動いてくれない。

**結論**

「交渉が進んだ」と「海峡が戻った」はまだ別ニュース。条件合意と、安全に繰り返し船が通れる状態の両方がそろって初めて再開だ。

主な参照元：[Reuters・外交](https://www.reuters.com/world/middle-east/iran-war-diplomacy-turns-toward-reopening-strait-hormuz-2026-08-28/)、[Reuters・通航](https://www.reuters.com/business/energy/shipping-traffic-via-strait-hormuz-slips-below-10-day-average-data-shows-2026-08-28/)、[Al Jazeera](https://www.aljazeera.com/amp/economy/2026/8/28/iran-says-it-will-name-its-terms-for-reopening-strait-of-hormuz)

### 8．【暮らし・経済】中国・美団が四半期黒字へ　「1時間配送」の値引き戦争にようやくブレーキ

**何が起きたか**

中国のフードデリバリー大手・美団は28日発表の4～6月期決算で黒字へ転換し、売上高の伸びも市場予想を上回った。中国では美団、アリババ系、JD.comなどが即時配送を巡って大規模な値引きや補助金を投入してきたが、激しい価格競争には緩和の兆しが出ている。

**賛**

赤字覚悟の補助金競争が永遠に続くより、サービス単体で採算を取れる方が健全。配送員や加盟店を含めて長く維持するなら、「誰かがずっと赤字をかぶる」モデルからは抜けた方がいい。

**ただぁ！**

ただぁ！ 価格戦争の一番うまい時期を経験した消費者は、その値段をすぐ「普通」だと思う。企業が補助金を引っ込めた瞬間に、便利さの本当の値段だけが後から届く。

**結論**

1時間配送そのものが残るかより、戦争級の値引きなしで客が同じだけ使うかが次の勝負。安さはサービスではなく、一時的な弾薬だった可能性がある。

### 9．【科学・気候】エルニーニョ変動、産業革命前より36.5％大きいとの研究　ガラパゴスのサンゴで千年を復元

**何が起きたか**

Scienceに掲載された研究で、ガラパゴス諸島のサンゴ記録を使って過去約1000年のエルニーニョ・南方振動（ENSO）を復元した結果、現代の東部太平洋のENSO変動幅が産業革命前の千年間より36.5％大きいと推定された。特に直近約40年で強まりが目立ち、研究チームは人為的な温暖化が変動を増幅している可能性を示した。一方、観測やモデルとの整合について慎重な見方もある。

**賛**

数十年の観測だけでは分かりにくい現象を、サンゴから千年規模まで伸ばして比較できるのは大きい。気候変動が平均気温だけでなく、変動の振れ幅へどう効くかを見る材料になる。

**ただぁ！**

ただぁ！ これは「最近の洪水や猛暑は全部この研究で説明できます」という万能スタンプではない。長期的なENSOの振れ幅が強まったという研究と、個々の災害を何がどれだけ悪化させたかというイベント帰属は別の仕事だ。

**結論**

背景のサイコロが荒くなっている可能性は重い。ただし、出た目を全部「気候変動のせい」で雑に片づけないことまで含めて科学だ。

主な参照元：[AAAS / EurekAlert!](https://www.eurekalert.org/news-releases/1141187)、[AP](https://apnews.com/article/cf2e0bbe4b241c5ad0141ca0f93f44dd)、[Nature](https://www.nature.com/articles/d41586-026-02717-9)

### 10．【国際・安全保障】日米韓、9月7日から「Freedom Edge」　対北朝鮮で対話と抑止を同時運転

**何が起きたか**

日本、米国、韓国は9月7～11日、韓国・済州島の東・南側の公海で3カ国共同訓練「Freedom Edge」を実施する。海・空・サイバーなど複数領域を組み合わせ、弾道ミサイル防衛や対潜水艦戦などを訓練する予定。米韓は北朝鮮との対話環境を意識して別の合同演習を縮小しているが、3カ国訓練は予定通り行う。

**賛**

ミサイル防衛や対潜水艦戦は、一国だけ強くても情報共有と連携が噛み合わなければ意味が薄い。実際に三者で動く訓練を続けることは抑止力の実務になる。

**ただぁ！**

ただぁ！ 一方では「対話のため演習を少し抑えます」、もう一方では5日間の3カ国訓練をやる。対話と抑止を同時に出す戦略はあり得るが、受け手が都合よく両方の意図を読み取ってくれる保証はない。

**結論**

対話と抑止は両立できる。でも二つの信号を同時に点灯するなら、何を縮め、何は譲らないのかまで説明しないと、相手には赤信号だけ見える。

主な参照元：[AP](https://apnews.com/article/a953d60690bf861f134e36a021bdbd70)、[時事通信 / nippon.com](https://www.nippon.com/en/news/yjj2026082800401/)
