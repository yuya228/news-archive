### 1．【社会・安全】台風25号、関東で4人死亡・6人不明　約4万5000戸で停電

**今回の差分**

21日は台風接近による記録的大雨と交通混乱を扱った。22日は被害の全容が広がり、死者・行方不明者が確認され、救助と復旧の段階へ移った。

**何が起きたか**

台風25号（ドゥージェン）がもたらした豪雨で、関東では土砂崩れや浸水が相次ぎ、22日午後までに4人が死亡、6人が行方不明となった。千葉県を中心に約4万5000戸が停電し、伊豆大島では48時間雨量が832ミリに達した。台風は日本から遠ざかったが、警察や消防による捜索が続いている。

**賛**

台風通過後すぐに捜索・復旧へ移り、警報も状況に応じて解除・引き下げられている。危険度を更新しながら動くのは災害対応の基本だ。

**ただぁ！**

ここは被害を笑う話ではない。台風が海へ抜けても、土砂の中に人が残り、停電した家も残る。「台風は去った」という天気図の表現と、被災地の日常が戻る時刻は一致しない。

**結論**

今日の焦点は天気ではなく救助と復旧。通過後こそ、崩れた斜面や増水した川へ不用意に近づかないことが重要だ。

### 2．【スポーツ】日本クリケット、世界王者インドに2点差　初対戦で大金星寸前

**何が起きたか**

栃木県佐野市で22日、日本男子クリケット代表がT20世界王者インドと史上初の国際試合を行った。台風後のグラウンド状態の影響で通常20オーバーの試合は5オーバーずつに短縮。日本はインドを32得点・4アウトに抑え、追う日本も30得点まで迫ったが、2点差で敗れた。日本にとって国際クリケット評議会の正会員国との男子初対戦だった。

**賛**

結果は敗戦でも、世界王者を32点に抑えて最後まで勝敗が分からなかった。日本ではまだ小規模な競技が、トップ国と公式に戦えるところまで来た意味は大きい。

**ただぁ！**

歴史的な20オーバー戦が雨で5オーバー戦になり、初対戦からいきなり超短期決戦。競技普及の晴れ舞台なのに、台風がルール説明まで難しくしてくれた。それでも2点差なら、むしろ覚えてもらうには強烈だった。

**結論**

「日本にクリケット代表があるの？」から一歩進んで、「世界王者に2点差だった」が説明に使える。普及にはかなり良い負け方だった。

### 3．【社会・行政】入管、建設現場などの違法就労対策を強化　他省庁の巡回に同行へ

**何が起きたか**

出入国在留管理庁は、違法就労対策として国土交通省などとの合同対応を強化する。早ければ10月から、解体・建設現場の巡回に入管職員が同行し、在留カード確認や行政指導、必要な法執行につなげる。環境省や農林水産省との連携も検討している。入管によると、昨年に退去強制手続きの対象となった外国人の7割超に不法就労が確認された。

**賛**

現場を巡回する自治体職員だけでは在留資格を直接確認できない場合がある。権限を持つ入管職員が同行することで、役所同士の「担当外です」を減らせる。

**ただぁ！**

取り締まりだけ強くしても、違法な働かせ方をする事業者側を放置すれば人が入れ替わるだけ。外国人労働者だけを問題の主体にせず、雇う側の責任まで同じ強さで見る必要がある。

**結論**

現場確認の強化は必要。ただし「働いた人を捕まえる」で終わらず、「違法に働かせて利益を得た側」まで追えるかが本番だ。

### 4．【スポーツ・社会】韓国選手団、アジア大会の宿泊・輸送問題に正式謝罪を要求

**今回の差分**

18日は選手村を作らない分散宿泊方式への不満、19日は開幕後の運営問題を扱った。22日は韓国選手団長が一連の問題を「運営上の欠陥」と批判し、正式な謝罪と具体的な再発防止策を求めた。

**何が起きたか**

愛知・名古屋アジア大会で、韓国選手団が宿泊と輸送を巡る問題について大会組織委員会へ正式な対応を要求した。男子バスケットボール代表は宿泊施設の浸水でホテルへ移動し、送迎バスが来ず練習を取りやめた事例もあった。韓国ホッケーチームの試合で誤って北朝鮮国歌が流れた問題では大会側が謝罪している。

**賛**

大会中だから黙って耐えるより、具体的な事例を示して改善を求める方が後半の競技にも次回大会にも役立つ。

**ただぁ！**

大会前には「選手村を作らないのは負の遺産を避けるため」と説明されていた。節約の理念は理解できても、バスが来ないことや国歌を間違えることまで持続可能性では説明できない。そこは普通に運営品質の話だ。

**結論**

低コスト大会の実験と、雑な大会運営は別物。費用を削っても、選手が競技へ行けるところまでは削ってはいけない。

### 5．【暮らし・文化】SLやまぐち号のC57、約6年ぶり復帰へ　部品メーカー消滅で船舶部品会社に特注

**何が起きたか**

JR西日本の観光列車「SLやまぐち号」を牽引するC57形蒸気機関車が大規模修理を終え、10月3日に約6年ぶりに営業運転へ復帰する。1937年製の車両で、2020年にピストンの不具合で運行不能となった。蒸気機関車用の部品メーカーがすでになく、修理では船舶部品メーカーへ部品を特注した。

**賛**

90年近い機械を安全基準に合わせて走らせ続けるには、保存だけでなく技術継承が必要になる。観光資源として地域へ人を呼ぶ役割もある。

**ただぁ！**

「古いものを大切に」で済む話ではなく、部品を作る会社そのものが消えている。SLを残すとは車体を磨くことではなく、存在しないサプライチェーンまで毎回つくり直すことになってきた。

**結論**

6年かけて復活するだけで十分すごい。次の課題は、走る文化財を誰が直せるのかという技術そのものを残すことだ。

**何が起きたか**

中国Alibabaは22日、自社開発のAI向け半導体「Zhenwu V900」を発表した。会社説明では前世代の3倍の計算性能を持ち、最大50万個を組み合わせて大規模AIを動かせる。さらに現在の主力モデルより大幅に大きい、5兆～10兆個の調整項目を持つ次世代AIモデルの開発方針も示した。データセンター容量は2032年までに20ギガワット超を目指す。

**賛**

AIソフトだけでなく、半導体とデータセンターまで自前で揃える戦略は、中国が海外製AIチップに依存しにくくするうえで合理的だ。

**ただぁ！**

数字はとにかく巨大だが、AIは調整項目の数が多ければ自動的に賢くなるわけではない。50万チップ、10兆パラメーター、20ギガワットと桁が並ぶほど、電力・製造・運用という地味で巨大な請求書も一緒についてくる。

**結論**

「大きいAI」の競争が、モデルだけでなく発電所級のインフラ競争になっている。次に見るべきは数字の迫力ではなく、実際の性能と供給量だ。

### 8．【スポーツ】F1、2027年からレースを約15km短縮　2～3周少なく

**何が起きたか**

F1委員会は、2027年から通常のグランプリ距離を305kmから290kmへ短縮する方針を承認した。サーキットによって2～3周短くなる。2027年のエンジン規則変更に合わせた措置で、雨などで中断したレースでは現在の「開始から3時間」の上限を廃止し、別の終了時刻ルールを導入する。最終的な規則変更にはFIA世界モータースポーツ評議会の承認が必要。

**賛**

エンジン規則を変えるなら、燃料タンクを大きくして従来距離を無理に維持するより、競技全体を調整する選択肢はある。中断時に観客がレースを見られる時間を確保する狙いも分かる。

**ただぁ！**

F1は長年「約305km走る競技」だったので、15km削るのは小さく見えて歴史的にはかなり珍しい変更。速さを競う世界が、とうとう「ちょっと短く走ろう」で技術規則との帳尻を合わせる。

**結論**

短縮だけ見れば数分の差だが、燃料・戦略・タイヤには効く。2027年F1はマシンだけでなく、レースそのものの尺まで変わる。

**主な参照元：** [FIA](https://www.fia.com/news/formula-1-commission-meeting-210926-media-statement)、[Reuters](https://www.reuters.com/sports/formula1/f1-commission-agrees-shorter-races-2027-2026-09-21/)

### 9．【社会・政治】CNNなどがホワイトハウス入場禁止を提訴　主要テレビ局は共同取材を停止

**何が起きたか**

CNN、MS NOW、Politicoは、トランプ米大統領が3社のホワイトハウス取材資格を取り消したことについて、言論・報道の自由を侵害するとして連邦裁判所へ提訴した。CNNを含む主要テレビ局が交代で映像を共有する「プール取材」では、他局も連帯して大統領の共同映像取材を停止した。

**賛**

政府と報道機関が対立した時に、最終的な線引きを裁判所へ持ち込むのは制度として健全だ。取材資格を政権への好悪だけで決められるのかは司法が判断すべき論点になる。

**ただぁ！**

嫌いな報道を締め出せば批判が減るどころか、残ったテレビ局までカメラを止めた。取材制限で情報を管理しようとして、結果として大統領自身の映像が減るなら、広報戦略としてもかなり高くつく。

**結論**

これはCNNの好き嫌いではなく、政府が記者を選別できる範囲の問題。裁判所がどこに境界線を引くかが本体だ。

### 10．【IT・安全】MetaのAIアシスタント「Muse」に重大な欠陥　Mac上の別アプリから乗っ取り可能と研究者

**何が起きたか**

macOSのセキュリティ研究者Patrick Wardle氏は22日、MetaのAIアシスタント「Muse」の設定を同じMac上の別アプリやコマンドから変更し、認証情報を奪ってMuseを操作できる脆弱性を公表した。Museはメール、カレンダー、ファイルなど幅広いサービスと接続して利用する設計のため、乗っ取られた場合の権限も大きい。現時点で実際の大規模悪用が確認されたとの情報はない。

**賛**

実害が広がる前に研究者が具体的な攻撃方法を示し、AIエージェント特有の権限設計を検証できる材料が出た意味はある。

**ただぁ！**

AIエージェントは「代わりに何でもやってくれる」ほど便利だが、乗っ取った側にも同じ「何でも」が渡る。普通のアプリなら一つの情報漏えいで済む欠陥が、代理人AIではメール送信やファイル操作まで連鎖する可能性がある。

**結論**

AIエージェントは賢さより先に権限管理が商品品質になる。MuseのMac版は、修正状況を確認できるまでは重要なアカウントを広く接続しない方が安全だ。

**主な参照元：** [iTnews](https://www.itnews.com.au/news/security-researcher-says-dont-install-metas-muse-ai-assistant-629088)、[India Today](https://www.indiatoday.in/amp/technology/news/story/muse-is-new-ai-sensation-it-is-helpful-from-mark-zuckerberg-and-potentially-dangerous-2999970-2026-09-22)
