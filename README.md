### 1．【暮らし・経済】7月の実質消費3.6％減　8カ月連続マイナス、賃上げだけでは財布が開かない

**何が起きたか**

総務省が4日公表した7月の家計調査で、二人以上の世帯の消費支出は1世帯あたり30万1245円となり、物価変動を除いた実質で前年同月比3.6％減った。前月比では0.5％増えたものの、前年同月比では8カ月連続の減少で、Reutersによると約2年半ぶりの大きな落ち込み。勤労者世帯の実収入も実質3.8％減だった。

**賛**

景気を「賃金が上がった」「株価が上がった」だけで見ず、実際に家庭が何へお金を使えたかまで数字で確認できるのは大事だ。日銀が利上げを考える局面だからこそ、物価と消費の両方を見る必要がある。

**ただぁ！**

ただぁ！ 賃上げのニュースが増えても、物価上昇で実収入が減れば家計は普通に防御モードへ入る。給料の額面が増えたかより、スーパーと家賃と交通費を払った後に何円残るかの方が、消費には正直だ。

**結論**

「賃上げできたから消費も強い」はまだ成立していない。9月の日銀会合では、インフレを抑えたい金利政策と、弱い家計消費をどう両立させるかがさらに難しくなる。

### 2．【社会・防災】宮崎で24時間333ミリ　昨日の「長雨予測」が避難指示・冠水・通行止めへ

**今回の差分**

3日は台風24号と秋雨前線で、宮崎を中心に長時間の大雨となる可能性を扱った。4日は都農町で24時間333ミリを観測し、複数の市町で避難指示や土砂災害危険警報、道路冠水・倒木・通行止めが実際に発生した。

**何が起きたか**

台風24号と秋雨前線へ流れ込む湿った空気の影響で、宮崎県では4日に大雨が続いた。宮崎市、都農町、国富町、綾町などで避難指示が出され、日向市では市道が冠水。国道268号は土砂流出で一部通行止め、東九州自動車道も門川IC～清武ICで通行止めとなった。午後4時前の時点でも夜遅くにかけて線状降水帯発生の恐れが残っていた。

**賛**

昨日の段階で総雨量のリスクを先に出していた意味は、今日の交通規制や避難判断につながって初めて見える。台風の中心だけ追わず、前線と長雨をセットで警戒する必要性がはっきりした。

**ただぁ！**

ただぁ！ 大雨予測は「当たった・外れた」の一発採点ではない。地域ごとの雨量は刻々と変わる一方、道路や斜面は一度傷むと次の雨に弱くなる。予報の数字が更新されても、現場のダメージまで更新前に戻るわけではない。

**結論**

昨日は予測、今日は実害。ここからは台風の進路図より、避難情報・道路規制・土砂災害の危険度を優先して見る局面だ。

主な参照元：[FNN・台風24号大雨](https://www.fnn.jp/articles/-/1107904)、[テレビ宮崎](https://www.fnn.jp/articles/-/1108009)

### 4．【IT・交通】自動運転の「安全」を保険データで採点　NTTモビリティとあいおいが武蔵野市で実証

**何が起きたか**

NTTモビリティとあいおいニッセイ同和損保は4日、東京都武蔵野市で自動運転の安全性評価を高度化する共同実証を始めると発表した。2026年9月～2027年3月、武蔵野市役所～吉祥寺駅周辺で、トヨタ「e-Palette」ベースのレベル2自動運転車両を走らせる。車両の走行データと、あいおい側がテレマティクス保険で蓄積してきた運転挙動・ヒヤリハット等のデータを比較し、自動運転固有のリスクを可視化する。

**賛**

自動運転車が「事故らなかったから安全です」と自分の走行結果だけで自己採点するより、人間ドライバーの大量の実走データと比べる方が客観的な物差しを作りやすい。保険会社の事故リスク分析を使うのは役割分担としてかなり自然だ。

**ただぁ！**

ただぁ！ 今回はレベル2の実証で、運転主体を完全にシステムへ渡すレベル4の安全を証明したわけではない。データが222万台規模あっても、「人間より安全」の一言へ変換するには、走行条件や危険場面の揃え方まで詰める必要がある。

**結論**

自動運転の社会実装で次に必要なのは、走れる動画より「どの基準なら安全と判定するか」。技術競争から採点基準づくりへ、一段地味だけど重要なフェーズに入っている。

9日たってから生存者を救出できた事実は、道路復旧や重機投入を諦めず続ける意味そのものだ。トンネルの構造図や現場情報を共有しながら、救助隊が空間を一つずつ探した成果でもある。

**結論**

道路が戻った日に終わらず、9日目に2人が戻ってきた。救助は時間との勝負だけど、「もう遅い」と決めつけないことも現場では命に直結する。

### 10．【暮らし・農業】フランス、干ばつ・猛暑被害へ10億ユーロ超　農家救済は「今年を耐える」と「来年作る」の二段構え

フランス政府は4日、夏の猛暑と深刻な干ばつで打撃を受けた農家へ、10億ユーロ超の支援策を発表した。農相アニー・ジュヌヴァール氏によると、まず国の農業災害補償制度などを使って資金繰りを支え、破綻を防ぐ。政府は損失補償に約5億2000万ユーロを見込み、飼料や種子の購入など生産再開を支える基金も設ける方針だ。

**賛**

災害後の農業支援は、今年の赤字を埋めるだけでは足りない。種子や飼料を買えず翌年の生産まで落ちれば、農家の経営問題がそのまま食料供給問題になる。緊急資金と再生産支援を分けたのは合理的だ。

**ただぁ！**

**結論**

今回の支援は必要な救急処置。でも本当の農業政策は、次の猛暑でも同じ10億ユーロを払わずに済む仕組みを作れるかで決まる。
