### 3．【社会・防災】屋久島の5日間雨量1000ミリ超　台風24号、奄美でも線状降水帯

**今回の差分**

5日は屋久島で24時間雨量が観測史上最多となり、土砂災害の危険度が警戒レベル5相当まで上がったことを扱った。6日は雨が一日で終わらず、屋久島町の5日間の総雨量が1000ミリを超え、5日夜には奄美地方でも線状降水帯が発生した。

**何が起きたか**

台風24号は6日正午時点で奄美大島の南の海上を東寄りに進み、奄美地方は強風域に入った。MBCによると屋久島町では2日からの5日間で雨量が1000ミリを超える記録的大雨となった。5日夜には奄美地方で線状降水帯が発生し、6日午後以降は関東でも警報級の大雨となる可能性が示された。屋久島では地盤が大量の雨を含んだ状態が続いており、土砂災害への厳重警戒が必要とされた。

**賛**

「今日の雨が何ミリか」だけでなく、数日分の累積雨量と地盤の状態まで見て警戒を続けるのは重要だ。雨雲が弱まる時間があっても、斜面の危険度まで即座にリセットされるわけではない。

**ただぁ！**

ただぁ！ 昨日は「24時間で観測史上最多」、今日は「5日で1000ミリ超」。雨量の単位がどんどん大きくなると感覚が麻痺するが、山からすると全部同じ地面に入ってくる水である。

**結論**

今回は台風の現在地より、これまでに降った総量の方が怖い。天気図が動いても、地盤には「既読にして忘れる」機能がない。

主な参照元：[MBCニュース（livedoor配信）](https://news.livedoor.com/article/detail/32254646/)、[テレビ朝日](https://news.tv-asahi.co.jp/news_society/articles/900199000.html)

**今回の差分**

**何が起きたか**

第13シードの大坂は第1セットを取った後、第2セットを落とし、最終セットでも苦戦。終盤には左アキレス腱の問題で治療を受けたが、そこから持ち直して勝利した。大坂は試合後、この問題が芝シーズンから続いていると説明している。全米で16強入りするのは今回が5度目で、次戦はエレーナ・ルバキナと対戦する。

**賛**

調子が落ちたうえに身体の不安まで出た試合を、試合中に立て直して勝ち切ったのは強い。グランドスラムの後半は毎日100点の選手より、70点の日でも落ちない選手が残る。

**ただぁ！**

ただぁ！ 前回の宿題「崩れる時間を短く」は、提出期限を次戦へ延長。とはいえ、怪我まで追加された日に勝っているので、先生側も強くは言えない。

**結論**

勝ち上がりは順調でも、アキレス腱は無視できない。次は相手だけでなく、自分の身体と相談しながらの16強になる。

**何が起きたか**

インドネシアのアナク・クラカタウ火山の噴火が続き、6日はジャカルタのスカルノ・ハッタ国際空港など複数空港が火山灰のため一時運航を停止した。Reutersによると、301便が影響を受け、このうち58便が国際線。火山灰はスマトラ側で高度5万フィート付近まで確認され、一部地域では学校活動や漁業も停止された。国家防災庁BNPBはマスク配布などを進め、火山活動を監視している。津波警報は出されていない。

**賛**

火山灰はジェットエンジンに深刻な障害を起こし得るので、空港閉鎖は過剰反応ではなく安全側の判断だ。空港、学校、漁業を別々に見るのではなく、灰の広がりに合わせて生活圏全体で止める必要がある。

**ただぁ！**

ただぁ！ 飛行機は時刻表通りに動きたくても、火山灰にはダイヤ改正の相談窓口がない。301便を止めたのは航空会社の都合ではなく、空そのものが使用停止になったからである。

**結論**

復旧時刻だけ追うより、灰の拡散と火山活動の継続を見るべき局面。空港が再開しても、噴火が止まったとは限らない。

ただぁ！ ドローン対策の話から読み進めると、Cyberdome、AI、顔認証、駅の監視カメラまで全部乗ってくる。防犯セットを注文したら、いつの間にか国民側のプライバシーもオプション欄に入っている。

**結論**

安全保障強化の必要性と監視拡大の妥当性は別々に採点すべきだ。脅威が本物でも、「だから全部見ていい」まで自動承認にはならない。

ただぁ！ OPEC+が「増産します」と数字を足しても、戦争で船が通らなければ市場には届かない。レストランのメニュー表で席数を増やしているのに、厨房への道が封鎖されているようなものだ。

**結論**

今の石油市場では、割当量より実際に何バレル出荷できるかが本体。OPEC+の会議室より、ホルムズ海峡の方が価格決定力を持つ時間が続いている。
