### 1．【経済・暮らし】日銀、政策金利を1.25％へ　31年ぶり高水準でも円は下落

**何が起きたか**

日本銀行は18日の金融政策決定会合で、政策金利を1.0％から1.25％へ引き上げた。7対2の賛成多数で、金利水準は31年ぶりの高さ。植田和男総裁は、基調的な物価上昇率が2％へ近づくなか、政策の重点が「物価を2％まで押し上げる」段階から「2％を上回るリスクを防ぐ」段階へ変わったと説明し、追加利上げの可能性も残した。一方、市場では今後の利上げペースへの慎重論が意識され、円は対ドルで下落した。

**賛**

原油高や円安で輸入物価が再び上がりやすい状況なら、物価が跳ねてから慌てて大幅利上げするより、先に小幅で動くという考え方には合理性がある。

**ただぁ！**

金利を上げれば円高、という教科書の矢印どおりには動かなかった。市場が見ているのは今日の0.25％だけでなく、その次を本当に続けるのかという覚悟まで込み。利上げしたのに円安という結果は、政策金利の数字だけでは市場を説得できないことを示している。

**結論**

31年ぶりという見出しは大きいが、住宅ローンや企業借入には現実の負担増になる。次の焦点は「さらに上げるか」と「それでも円安が止まらない場合にどうするか」。

**主な参照元：** [日本銀行](https://www.boj.or.jp/mopo/mpmdeci/state_2026/index.htm)、[Reuters](https://www.reuters.com/world/asia-pacific/bank-japan-set-raise-interest-rates-31-year-high-2026-09-17/)

### 2．【経済・暮らし】8月のコアCPIは1.7％　8カ月連続で日銀目標の2％下回る

**何が起きたか**

総務省が18日に公表した8月の全国消費者物価指数で、生鮮食品を除く総合指数は前年同月比1.7％上昇した。7月の1.8％から鈍化し、日銀の2％目標を8カ月連続で下回った。生鮮食品とエネルギーを除く指数は1.9％上昇。政府の電気・ガス料金支援が全体を抑える一方、中東情勢による燃料高や円安は今後の上振れ要因になっている。

**賛**

少なくとも足元の数字だけなら、物価が制御不能に加速している状態ではない。エネルギー支援が家計負担を和らげている効果も数字に出ている。

**ただぁ！**

その同じ日に日銀は利上げした。CPIが2％未満だから安心、ではなく、中央銀行は「これから上がるかもしれない」を見て先回りしている。家計からすると、物価の上昇はまだ残り、借入金利は先に上がるという少し納得しづらい時間差である。

**結論**

1.7％だけ見て「インフレ終了」とは言えない。補助金が切れた後、原油高と円安がどこまで小売価格へ移るかが本番になる。

**主な参照元：** [総務省統計局](https://www.stat.go.jp/data/cpi/1.htm)、[Reuters](https://www.reuters.com/world/asia-pacific/japans-august-core-consumer-prices-rise-17-yryr-2026-09-17/)

### 4．【スポーツ・社会】アジア大会、選手村なしをOCAが擁護　コンテナ型宿泊施設やクルーズ船を活用

**今回の差分**

16日は19日の正式開幕を前に大会規模を扱った。18日は、選手村を建設しなかったことで生じた宿泊環境への不満に対し、アジア・オリンピック評議会（OCA）が「大会後の負の遺産を避けるため」と説明した。

**何が起きたか**

愛知・名古屋アジア大会では、約1万7000人の選手・関係者をホテル、コンテナ型の仮設宿泊施設、クルーズ船などに分散して収容する。費用を抑えるため当初の選手村計画を撤回した一方、狭い部屋や短いベッド、男女選手の相部屋割り当てなどへの不満が出た。OCAは18日、恒久的な選手村を建てれば大会後に使われない「白い象」になり得るとして、柔軟な方式を擁護した。

**賛**

数週間の大会のために巨大住宅群を建て、終わった後の維持費を地元へ残すより、既存施設や一時設備を使う発想は持続可能性の面で分かる。

**ただぁ！**

「負の遺産を作らない」は正しい。でも、その節約のしわ寄せを現役選手のベッド幅で回収したら順番が逆になる。豪華な選手村は不要でも、競技に集中できる最低限の宿泊品質は削ってはいけない。

**結論**

選手村を作らない実験自体は価値がある。成功かどうかは建設費ではなく、大会後の財政と大会中の選手満足度を両方見て判断すべきだ。

### 5．【IT・科学】九州大、高出力レーザーで宇宙の「磁気リコネクション」を再現

**何が起きたか**

九州大学の研究チームは18日、太陽フレアや地球磁気圏のサブストームなどで起きる「磁気リコネクション」を高出力レーザーで実験室内に再現し、その高速なエネルギー解放を左右する仕組みを調べた研究成果を発表した。結果は、周囲のプラズマ全体の性質より、磁場がつなぎ替わる局所領域の物理が速度を支配することを示した。

**賛**

宇宙で起きる巨大現象を待って観測するだけでなく、地上で条件を変えながら再現できれば、宇宙天気モデルの検証材料を増やせる。太陽活動が通信や衛星へ与える影響の理解にもつながる基礎研究だ。

**ただぁ！**

太陽フレア級の仕組みを理解するため、地球で高出力レーザーを撃って小さく再現する。スケール感だけ聞くと無茶だが、科学は「宇宙まで行けないので実験室に宇宙の一部を持ってきました」を本当にやる。

**結論**

すぐスマホが速くなる研究ではない。ただ、宇宙天気を予測する理論の土台を実験で確かめられる意味は大きい。

**主な参照元：** [九州大学](https://www.kyushu-u.ac.jp/en/researches/view/425)、[Brightsurf](https://www.brightsurf.com/archive/2026/september/18)

### 9．【科学・動物】100年以上ぶりに新種のネコ科を正式記載　ボリビアの「ティルカヨ」

**何が起きたか**

国際研究チームは、ボリビアのユンガス地方に生息する小型の野生ネコを独立種 `Leopardus tilcayo` として正式記載した。現生ネコ科で、この形で完全な新種が正式に記載されるのは100年以上ぶり。体長は約46cm、体重は約1.4kgで、平均的な家猫より小さい。研究チームは南米各地の `Leopardus` 属38個体の全ゲノムを比較し、ティルカヨの系統が他のタイガーキャット類から約140万年前に分岐したと推定した。研究は17日付のCurrent Biologyに掲載された。

**賛**

見た目が珍しい猫を1種増やしただけではなく、ゲノム解析によって、従来ひとまとめに考えられてきたタイガーキャット類を5つの異なる種へ整理した研究でもある。分類が細かくなれば、それぞれの分布や絶滅リスクを別々に評価し、保全策を組み立てやすくなる。

**ただぁ！**

名前が付いた瞬間に、生態まで全部分かったわけではない。研究チームが直接調べた生きたティルカヨはわずか2個体で、野生個体数もまだ分からない。100年以上ぶりの新種なのに、「何匹いるのか」から調査中である。

**結論**

猫だからニュースになるのではなく、ネコ科の系統樹を書き換えたからニュースになる。しかも1.4kg。次に重要なのは、見つけた後に消さないことだ。

**主な参照元：** [Current Biology](https://doi.org/10.1016/j.cub.2026.08.059)、[Reuters](https://www.reuters.com/business/environment/new-cat-species-identified-bolivia-first-over-century-2026-09-17/)、[National Geographic](https://www.nationalgeographic.com/animals/article/meet-the-first-new-cat-species-discovered-in-100-years)
