### 1．【社会・安全】台風25号が関東を直撃　伊豆大島で500ミリ超、航空・鉄道にも大きな影響

**今回の差分**

20日は「21日に関東へ接近し、交通が乱れる可能性」を扱った。21日は予報が実害へ変わり、伊豆諸島や関東で大雨となり、航空便の大量欠航や鉄道運休、アジア大会の競技延期まで発生した。

**何が起きたか**

台風25号（ドゥージェン）が21日に関東へ接近し、伊豆大島では午後までの24時間雨量が500ミリを超えた。気象当局は土砂災害や洪水への厳重な警戒を呼びかけ、JALとANAでは国内線を中心に多数の便が欠航。JR東日本も一部路線を運休し、愛知・名古屋アジア大会では馬術競技が22日に延期された。高市首相の国連総会出発も4時間遅れた。

**賛**

前日から交通機関やイベント側が運休・中止の可能性を出していたため、利用者が予定を変える時間は確保された。予報段階で動いた意味はあった。

**ただぁ！**

ここは災害被害を笑う話ではない。昨日の「運休するかも」が今日は「実際に止まった」へ変わった。台風対応は予報が当たったかではなく、当たった時に人を危険な場所へ残さなかったかで評価すべきだ。

**結論**

今回は早めの中止判断が正解だったことを、台風そのものが証明した。通過後も土砂災害や増水は残るので、「雨が止んだ」が安全宣言ではない。

### 2．【暮らし・社会】食料支援を求める世帯、1人1日の食費500円未満　2人世帯は490円

**何が起きたか**

セーブ・ザ・チルドレン・ジャパンの食料支援へ申し込んだ保護者8736人を対象とする調査で、2人世帯の1人あたり平均食費は1日490円となり、前年の533円から減った。6人世帯では361円。回答者の85.5％が過去1年間に家族に必要な食料を買えなかった経験があると答え、89％が食料支援を申し込んだ理由として物価高で十分な食料を買えないことを挙げた。

**賛**

「物価が高くて大変」という感覚を、実際に支援を必要としている世帯の食費まで落として可視化した意味は大きい。支援策を考える材料になる。

**ただぁ！**

この調査は日本の全世帯の平均ではなく、食料支援へ申し込んだ人たちが対象。それでも、値上げが続く中で食費そのものを前年より削らざるを得ない層がいるという数字は重い。「節約術」で片付ける段階を超えている家庭がある。

**結論**

500円という数字だけを一人歩きさせず、対象を正しく見るべきだ。その上で、食べる量を削って帳尻を合わせている家庭への支援は急ぐ必要がある。

**主な参照元：** [Nippon.com / 時事通信](https://www.nippon.com/en/news/yjj2026091900101/daily-food-spending-below-500-yen-among-needy-people-in-japan.html)、[The Japan Times](https://www.japantimes.co.jp/news/2026/09/21/japan/daily-food-spending/)

**何が起きたか**

サンリオは21日、Sanrio Gamesブランド初のスマートフォン向けタイトル「Sanrio Kawaii Me Live!」を2027年1月に世界配信すると発表し、事前登録を開始した。ハローキティやシナモロールなどが登場するダンス・リズムゲームで、基本プレイ無料・アプリ内課金方式。ずっと真夜中でいいのに。を含む音楽アーティストとのコラボも予定する。

サンリオはキャラクター商品を売るだけでなく、ゲームを通じて海外ファンと継続的に接点を持てる。自社IPを自社ゲームブランドで展開する意味は大きい。

**結論**

サンリオの強いキャラクター資産とスマホゲームの相性は良さそう。次に見るべきは事前登録100万ではなく、配信後に遊び続けてもらえるかだ。

### 4．【エンタメ・文化】東京ゲームショウ、台風で5日目を失い来場25万7642人　来年も5日間へ再挑戦

**今回の差分**

19日は台風接近による21日の最終日中止を扱った。今回は4日間で終了した2026年大会の来場者数が25万7642人となり、2027年も9月16～20日の5日間開催を予定することが明らかになった。

**何が起きたか**

東京ゲームショウ2026は17～20日の4日間で25万7642人が来場した。30周年で初の5日間開催を予定していたが、21日は台風25号のため会場開催を中止。一方で出展は53の国・地域から1138社・団体となり、ビジネスマッチングは3673件。来年は再び5日間開催を予定している。

**賛**

最終日を安全のため切った上で、一部プログラムをオンラインへ逃がしたのは現実的だった。ビジネス商談数が伸びた点も、単なる来場者数以外の価値を示している。

**ただぁ！**

30周年の「史上最長5日間」は天候で未完に終わったのに、来年も5日間へ再挑戦する。懲りないというより、今度こそ完走したい意地が見える。問題は日数を増やすこと自体ではなく、5日分の価値を作れるかだ。

**結論**

2026年は「5日間開催」ではなく「5日目を止められた大会」として成功した面もある。2027年は安全と内容の両方で、本当の5日間を完成させられるか。

**主な参照元：** [TOKYO GAME SHOW 2026](https://tgs.cesa.or.jp/2026/en)、[Final Weapon](https://finalweapon.net/2026/09/20/tokyo-game-show-2026-ends-early-with-in-person-attendance-of-257642/)

### 6．【IT・経済】中国、人型ロボット企業の上場ラッシュにブレーキ　「期待が実態を追い越した」と審査厳格化

**何が起きたか**

Reutersによると、中国当局は人型ロボット企業の相次ぐ株式上場に対し、審査基準を厳しくしている。Unitree Roboticsの株価が上場後の高値から大きく下落したほか、政府系のデータ収集施設や合弁事業への売上が実際の市場需要をどこまで表しているのかも精査されている。正式な上場禁止ではないが、投資熱を冷ます方向へ動いている。

**賛**

ロボット産業を育てることと、何でも高値で上場させることは別。製品が本当に売れ、使われているかを確認してから資金市場へ出すのは健全だ。

**ただぁ！**

人型ロボットは未来感だけなら満点だが、株式市場では「歩けます」より「誰が何台買いました」が必要になる。技術デモの拍手を、そのまま売上として計上することはできない。

**結論**

中国のロボット競争が終わる話ではなく、むしろ宣伝から商売へ進むための選別が始まった。次の勝者は動画で一番派手な会社ではなく、実際に使われる会社になる。

### 7．【IT・国際】米中、重大なAI事故を互いに知らせる仕組みを協議

**今回の差分**

20日は米中実務協議でAIが主要議題になったことを扱った。21日は米国側が、国家安全保障に影響し得るAI事故を互いに通知する新しい仕組みを中国側へ提案したことが明らかになった。

**何が起きたか**

ベッセント米財務長官は、中国の何立峰副首相との協議で、国家安全保障へ影響するAI事故について米中が情報を知らせ合う「通知メカニズム」を提案したと説明した。AI開発で競争する両国が、サイバー攻撃や重要インフラへの影響など共通リスクについて最低限の連絡経路を作れるかが焦点になる。

**賛**

AIで競争を続けるとしても、重大事故まで黙って殴り合う必要はない。核や航空のように、危険な誤解を避ける連絡経路を持つ発想には意味がある。

**ただぁ！**

最大の問題は「何を事故と呼ぶか」。自国では事故、相手国では攻撃と判断した瞬間に通知制度そのものが外交問題になる。電話番号を交換するより、共通定義を作る方が難しい。

**結論**

まだ提案段階だが、米中AI競争が性能だけでなく事故管理のフェーズへ入ったのは重要。仕組みができるなら、通知対象と検証方法が本体になる。

**主な参照元：** [AP](https://apnews.com/article/2c7f54f07e755f506d9db9b91df282bd)、[AP・米中AI安全](https://apnews.com/article/d08e58524de21511dcaba51f43faad95)

### 8．【経済・IT】Starbucks、インドに技術拠点　約800人を採用へ

**何が起きたか**

Starbucksはインド南部チェンナイにグローバル・ケイパビリティ・センターを設ける契約を結び、約800人の技術人材を採用する計画だとタミルナド州政府が発表した。拠点ではソフトウェア開発、財務、研究開発など本社を支える高度業務を担う。インドではこうした多国籍企業の技術・業務拠点が2100カ所を超えている。

**賛**

単なる低コストの事務処理拠点ではなく、ソフトウェアや研究開発まで置くなら、インド側には高技能雇用が増え、Starbucks側にも世界規模の運営を支える人材基盤ができる。

**ただぁ！**

コーヒー会社のニュースなのに、主役が豆ではなくエンジニア800人。今の巨大チェーンは店舗を増やすだけでは回らず、注文、会員、決済、物流までソフトウェア企業並みに作らないとコーヒー一杯を売れない。

**結論**

Starbucksの成長を支えるものが店舗数だけではなくなっている。次に見るべきは、800人規模の技術拠点が顧客体験や運営効率を実際にどう変えるかだ。

### 9．【経済】ベトナム株、FTSEの新興国指数入り　最大60億ドル流入の可能性

**何が起きたか**

ベトナム株が21日、FTSE Russellの新興国指数へ正式に組み入れられた。2018年から昇格候補となっていた市場にとって大きな節目で、指数会社は最大60億ドルの資金流入につながる可能性を見込む。組み入れは段階的に進み、外国人投資家の保有上限など課題も残る。

**賛**

国際指数への採用は、海外ファンドがベトナム株へ投資しやすくなる入口になる。市場制度を長年改善してきた成果でもある。

**ただぁ！**

「新興国指数に入った＝60億ドルが明日来る」ではない。指数組み入れは段階的で、外国人保有制限なども残る。昇格通知はゴールテープではなく、海外マネーに採点される本番の開始である。

**結論**

ベトナム市場には大きな追い風。ただし本当の評価は、資金流入が一時的な指数買いで終わらず、市場の厚みにつながるかで決まる。

### 10．【政治・社会】ドイツ与党が州選挙で歴史的惨敗　右派AfDと左派が伸長

**何が起きたか**

ドイツのメクレンブルク・フォアポンメルン州選挙で、メルツ首相率いるCDUが州議会入りに必要な5％を初めて下回る歴史的敗北となり、AfDが首位に立った。ベルリン州選挙でも左派党が最多議席を獲得する見通し。高い生活費、住宅問題、景気低迷への不満が既存の中道政党から左右の勢力へ流れた。

**賛**

有権者が生活費や住宅、経済政策への不満を選挙で示すのは民主主義の基本。既存政党が支持を失えば、政策を見直す圧力になる。

**ただぁ！**

中道が弱った結果、右と左が同時に伸びると、次の問題は「誰と組めるのか」になる。抗議票は簡単でも、議会では結局多数派を作らないと家賃も景気も直せない。

**結論**

メルツ政権への警告としてはかなり重い。ドイツ政治の焦点は、AfDの伸長だけでなく、中道政党が生活コストへの答えを出して支持を戻せるかに移った。
