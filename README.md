### 1．【経済・暮らし】円買い介入、1カ月で過去最大15兆3993億円　巨額でも円安の根っこは残る

**何が起きたか**

財務省は28日、7月30日から8月26日までの外国為替市場介入額が15兆3993億円だったと公表した。Reutersによると過去最大で、7月末に1ドル＝164円近辺まで円安が進んだ局面では、米国との異例の協調介入も行われた。その後いったん155円台まで円高が進んだが、8月中旬には159円台へ戻っている。

**賛**

急激な相場変動を放置すると、輸入企業も家計も価格設定が追いつかない。介入で一方向の投機を牽制し、「どこまでも円を売ればいい」空気を壊す意味はある。

**ただぁ！**

ただぁ！ 15兆円という数字は国家イベント級だが、金利差やエネルギー輸入という円安の原因そのものは介入では消えない。為替介入は相場に大声で「止まれ」と言えるけど、道路の傾斜までは直せない。

**結論**

過去最大額は本気度の証明。でも成功判定は「いくら使ったか」ではなく、円安の速度を落とし、金融政策や経済の地力へ時間を渡せたかで見るべきだ。

主な参照元：[財務省](https://www.mof.go.jp/policy/international_policy/reference/feio/data/monthly/20260828.html)、[Reuters](https://www.reuters.com/world/asia-pacific/japan-spent-record-965-billion-support-yen-over-past-month-ministry-data-shows-2026-08-28/)

### 2．【スポーツ】錦織圭、最後のグランドスラムは坂本怜に敗戦　20歳が本戦切符を取る

**何が起きたか**

全米オープン予選最終ラウンドで、36歳の錦織圭が20歳の坂本怜に4―6、6―7（3）で敗れた。今季限りで引退する錦織にとって、これがグランドスラム最後の試合となった。一方の坂本は19本のサービスエースを奪い、全米オープン本戦へ初進出。錦織は試合後、坂本を「次の日本のトップ選手」と評した。

**賛**

2014年に全米準優勝した選手の最後を、子どもの頃からその背中を見ていた日本人選手が止めて本戦へ行く。競技としてはこれ以上ないくらい分かりやすい世代交代だ。

**ただぁ！**

ただぁ！ 美談としては出来すぎているけど、坂本からすれば「憧れの人だから一回勝ちを譲ります」はプロでは一番いらない気遣い。引退ロードの感動演出より、本戦枠は一席しかない。

**結論**

錦織の全米は終わった。でも日本男子テニスまで一緒に最終回にしないために、坂本が勝った意味は大きい。継承って、花束を渡すより先輩を倒す方がずっと分かりやすい。

### 3．【政治・外交】北方担当相、プーチン氏の択捉訪問を「断じて許すものではない」　元島民は墓参再開を要求

**何が起きたか**

首脳による実効支配の誇示に対して、日本政府が立場を曖昧にしないのは当然。元島民が高齢化する中、墓参や交流の再開を具体的な課題として出し続ける意味もある。

ただぁ！ 「断じて許さない」は強い言葉だが、元島民が欲しいのは形容詞の強度ではなく、墓参に行ける日付と交渉の入口だ。抗議文だけ毎年筋トレしても、船は出ない。

主権の主張は曲げなくていい。ただ、返還という大目標と、墓参・交流をどう再開するかという目の前の実務を、同じ一枚のスローガンで済ませないことが必要だ。

### 4．【社会・防災】北陸で再び強雨　氷見は72時間525ミリ、被災地に追い打ち

**今回の差分**

27日は石川・富山への大雨特別警報と河川氾濫を扱った。29日は秋雨前線が再び活発化し、富山県氷見市の72時間降水量は525ミリと観測史上1位を大幅に更新。すでに被害が出た地域で、30日にかけて再び警報級の大雨となる恐れが出ている。

**何が起きたか**

29日も北陸で発達した雨雲が通過し、石川・富山では地盤が緩んだ状態が続く。富山県氷見市には土砂災害警報も出され、土砂災害、低地の浸水、河川の増水・氾濫への警戒が呼びかけられている。石川・富山では孤立者も残っている。

**賛**

一度の豪雨が終わった後こそ、「次の雨は同じ雨量でも危険度が違う」と繰り返し伝える必要がある。累積雨量と地盤の状態を前提に警戒を続けるのは正しい。

**ただぁ！**

ただぁ！ 災害はニュース上では「第1波」「第2波」と区切れても、現地の道路や斜面は前回分をセーブデータからやり直してくれない。復旧途中に次の雨が来ると、同じ50ミリでも意味が変わる。

**結論**

今回は雨の強さだけを見るより、「すでに壊れている場所へさらに降る」ことが本題。警報が一段下がった時間を、危険が消えた時間と読み替えない方がいい。

主な参照元：[FNNプライムオンライン](https://www.fnn.jp/articles/-/1103998)、[ウェザーニュース](https://weathernews.jp/news/202608/290241/)

### 5．【政治・IT】高市首相が「AI家庭教師」　音声だけで物価高対策シミュレーターを作成

**何が起きたか**

高市早苗首相は28日、官邸でチームみらいの安野貴博党首らから生成AIの活用方法について説明を受けた。首相は音声で指示し、家庭ごとの条件から政府の物価高対策の効果を試算する簡易シミュレーター作りを体験。5月の党首討論で安野氏が「AIの家庭教師」を申し出たことから実現した。

**賛**

AI政策を決める側が、資料で「生成AIとは」と読むだけでなく実物を触るのはいい。何が簡単で、どこで平然と間違えるかは、使わないまま規制を議論するより一度触った方が早い。

**ただぁ！**

ただぁ！ その場でアプリができると「政策もこれで高速化できる」と気持ちよくなりやすいが、AIが作った計算式の前提が間違っていたら、間違った政策効果を爆速で可視化するだけ。デモの速さと行政の正しさは別科目だ。

**結論**

首相がAIを触ること自体は歓迎。次の段階は「作れた、すごい」ではなく、誰が検証し、どのデータを使い、政策判断へどこまで入れるか。家庭教師の次は採点者が要る。

ただぁ！ Cursor利用者からすれば、企業買収のニュースを読んでいたら数カ月後に自分のモデル選択肢が変わる。AIツールは機能を買っているようで、実際には裏のモデル会社同士の契約にも人生を握られている。

**結論**

Musk対OpenAIの因縁は派手だけど、利用者にとって本題はそこではない。AIサービスの「このモデルが使えます」は機能一覧ではなく、契約が続く限り有効な借り物だ。

### 7．【IT・半導体】中国CXMTがLPDDR6量産、Xiaomi 18 Foldへ　自社チップの次はメモリも中国勢

**今回の差分**

24日はXiaomiが自社SoC「Xring O3」を発表し、製造はTSMCの3nmを使う話を扱った。29日は、そのXring O3を載せる予定の折りたたみスマホ「Xiaomi 18 Fold」に、中国CXMTの最新LPDDR6メモリが採用されることが明らかになった。

**何が起きたか**

CXMTはLPDDR6の量産開始を発表し、9月発売予定のXiaomi 18 Foldへ供給する。Xiaomiも採用を確認した。Reutersによると、CXMTはLPDDR5の生産開始から1年足らずで次世代規格へ進み、SamsungやSK hynixなどが強いDRAM市場で技術差を縮めている。

**賛**

スマホの頭脳だけでなくメモリまで供給先が増えれば、調達競争と価格競争が生まれる。中国勢が先端DRAMへ追いつくことは、世界の部品不足時に選択肢が増えるという面もある。

**ただぁ！**

ただぁ！ 「国産化が進んだ」で話を完結させると早い。Xring O3自体の製造はTSMCで、最先端スマホは設計・メモリ・製造装置・ファウンドリーが国境をまたいで成立している。自給自足の旗を立てても、基板の上はだいぶ国際連合だ。

**結論**

CXMTのLPDDR6量産は中国半導体の大きな前進。ただ本当の評価は、量産歩留まり、消費電力、供給量がSamsung・SK hynix・Micronと長期で競えるか。発表より出荷が本戦になる。

**賛**

老朽化したベネズエラの石油設備へ大規模投資が入り、生産が戻れば、ホルムズ海峡への依存が問題になっている世界の供給源を増やせる。エネルギーの選択肢が増えること自体には意味がある。

**ただぁ！**

ただぁ！ 650億バレルと書くと明日からガソリンが湧いてくる気分になるが、ベネズエラは世界最大級の埋蔵量を持ちながら現在の生産は世界の約1％。油田はExcelのセルではなく、掘削設備とパイプラインと政治の上にある。

**結論**

「史上最大級の石油取引」という見出しより、実際の増産ペースを見るべき。地下資源は在庫ではない。取り出して運べて初めて供給になる。

### 9．【国際・災害】ネパール洪水、復旧費40～50億ドル試算　「救助隊」より橋・トンネル・DNA支援を要請

**今回の差分**

26日は中国・ネパール国境の土石流と大規模な行方不明を扱った。29日はネパール政府が一般的な捜索救助は自国で続ける一方、トンネル救助、仮設橋、通信復旧、身元確認など専門分野の外国支援を求め、復旧費を40億～50億ドルと初めて試算した。

**何が起きたか**

氷河崩壊をきっかけとする洪水では、ネパールと中国・チベットで600人超の死亡が確認され、2000人以上がなお行方不明とされる。悪天候で捜索が難航し、ネパールでは約2ダースの橋が破壊された。インドや中国には仮設橋などの技術支援が要請されている。

**賛**

何でも「海外の救助隊を送ってください」とするより、自国でできる捜索と、国外の専門技術が必要な仕事を分けて要請する方が支援は噛み合いやすい。橋と通信の復旧は救助そのものにも直結する。

**結論**

今は被害総額を競う段階ではない。救える人を救いながら、国境山岳地帯の「一本切れたら孤立する」交通網をどう作り直すかまでが復旧になる。

### 10．【経済】FRBウォーシュ議長、インフレ続けば「仕事が残る」　利上げ観測が再浮上

**何が起きたか**

米連邦準備制度理事会（FRB）のケビン・ウォーシュ議長は28日、ジャクソンホールで講演し、基調的なインフレが2％目標へ十分な速さで戻っていると確信できなければ「やるべき仕事がある」と述べた。PCE物価指数は前年比3.7％で、ウォーシュ氏は雇用は安定し、金融環境も広く見れば強く引き締まっているとは言いにくいとの認識を示した。市場では9月利上げの確率が上昇した。

**賛**

物価が3％台後半なのに、景気が強いからと見て見ぬふりをすれば、後でより大きな利上げが必要になる可能性がある。データを見て必要なら動く、という姿勢自体は中央銀行として普通だ。

**ただぁ！**

ただぁ！ ウォーシュ氏は「フォワードガイダンスを減らしたい」と言いながら、その講演一発で市場は次の利上げ確率を計算し直す。中央銀行が未来を語らなくても、市場は句読点から未来を勝手に生成する。

**結論**

9月利上げはまだ決定ではない。むしろ今日のメッセージは、「先に答えは配らない、でも物価が下がらなければ動く」。市場にとっては不親切だが、政策としてはそのくらいの余白が本来ある。
